ℹ️ What is this lecture about?
This lecture covers how we improve the quality of digital images by applying mathematical operations directly on the pixel values in the spatial (image) domain. You will learn how kernels (filters) work, how to remove noise, how to sharpen edges, and the mathematics behind every technique.

Fundamentals of Spatial Domain Enhancements

Spatial Filtering (التصفية المكانية)
A technique that modifies an image by directly manipulating the intensity (brightness) values of pixels within a local neighborhood — without transforming the image to another domain (like frequency domain).

High Frequencies vs Low Frequencies

Every digital image can be thought of in terms of how fast pixel values change from one point to another. These changes are described using the concept of frequency:

⚡ High Frequencies — الترددات العالية

High frequencies represent rapid changes in pixel intensity over short distances. Examples:

  • Sharp edges (e.g., boundary of an object)
  • Fine texture details (e.g., fabric texture, hair)
  • Sudden transitions (e.g., object silhouette)
Crisp details and edge information live in high frequencies. Removing them causes blurring.
🌊 Low Frequencies — الترددات المنخفضة

Low frequencies represent slow, gradual changes in brightness. Examples:

  • Smooth background areas (e.g., sky, wall)
  • Broad color gradients
  • General illumination of a scene
Low frequencies carry the "big picture" structure. Removing them leaves only fine details/noise.
Think of an image as music. Low frequencies = bass notes (slow, steady background hum). High frequencies = treble notes (sharp, rapid changes). A Low-Pass Filter lets bass through (smooth), a High-Pass Filter lets treble through (edges).

Filters in Image Processing

A filter (also called a kernel or mask) is a small matrix of numbers that slides over the image and determines how each output pixel is computed from its neighbors. There are two broad categories:

CategoryPurposeEffectExample
Low-Pass FilterAllow low frequencies; block highBlurs/smoothens the imageGaussian, Box
High-Pass FilterAllow high frequencies; block lowSharpens edges, enhances detailLaplacian, Unsharp
LPF = Low Pass = "Lazy Blurring" — it lets slow changes through and blurs fast ones.
HPF = High Pass = "High Edge" — it keeps sharp edges and discards slow background.

أساسيات التحسين في المجال المكاني

🔹 الترددات العالية (High Frequencies)

تمثل التغيرات السريعة في سطوع البيكسلات على مسافات قصيرة.
أمثلة: الحواف الحادة لحدود الكائنات، تفاصيل النسيج الدقيقة، التغيرات المفاجئة.
إذا أزلناها: الصورة تصبح ضبابية (Blurred).

🔹 الترددات المنخفضة (Low Frequencies)

تمثل التغيرات البطيئة والتدريجية في السطوع.
أمثلة: الخلفيات الناعمة مثل السماء أو الجدران، التدرجات اللونية.
إذا أزلناها: تبقى فقط التفاصيل الدقيقة والضوضاء.

🔹 المصطلحات المهمة

  • Spatial Domain — المجال المكاني: تعديل الصورة مباشرة عبر قيم البيكسلات
  • High Frequency — تردد عالٍ: تغيرات سريعة = حواف وتفاصيل
  • Low Frequency — تردد منخفض: تغيرات بطيئة = خلفيات ناعمة
  • Low-Pass Filter — مرشح التمرير المنخفض: يحتفظ بالترددات المنخفضة ويزيل العالية (يُنعّم)
  • High-Pass Filter — مرشح التمرير العالي: يحتفظ بالترددات العالية ويزيل المنخفضة (يُحدّد)

⚠️ Common Mistake
Students often confuse "spatial domain" with "frequency domain." Spatial domain = working directly with pixel values. Frequency domain (Fourier) = transforming first, then filtering. This lecture focuses on spatial domain only.

Mathematical Foundations of Spatial Filtering

🔢 Filter Kernel (المرشح / النواة)
A filter kernel (also called a mask or window) is a small 2D matrix of coefficients that slides across the image. At each position, the kernel multiplies its values with the overlapping image pixels and sums the results to produce one output pixel.
  • Typical sizes: 3×3, 5×5, 7×7 (always odd to have a clear center)
  • The center cell of the kernel corresponds to the target pixel being computed
  • Larger kernels → smoother result but more computation

2D Convolution Equation

g(x, y) = Σs Σt w(s, t) · f(x+s, y+t)
Where: f = original image | g = output image | w = kernel coefficients | (x,y) = target pixel coordinates | (s,t) = kernel offsets

The equation says: "To compute the output pixel at position (x, y), multiply each coefficient in the kernel w by the corresponding pixel in image f, then sum all results."

The double summation (Σ Σ) iterates over all rows and columns of the kernel. For a 3×3 kernel, this is 9 multiplications + 8 additions per pixel.

ℹ️ Visual Intuition
Imagine placing a small magnifying glass (kernel) on each pixel, looking at the 8 neighbors around it plus itself (3×3 window). You do a weighted average of those 9 values based on the kernel weights to produce one output pixel. Then slide the glass one pixel to the right, repeat.

Edge Conditions — What Happens at Image Borders?

When the kernel is positioned near the image border, some kernel cells extend outside the image. There are three strategies:

⬛ 1. Zero-Padding (Zero-Fill)
Add a border of zeros (black pixels, value = 0) around the image before filtering. The most common and simple approach. The output image keeps the same size. Default
🪞 2. Mirroring (Reflection)
Reflect (mirror) edge pixels outward to create a symmetrical border. More natural results for many filters because border pixels aren't artificially set to 0. Better Quality
✂️ 3. Clipping (Cropping)
Simply don't compute output for pixels where the kernel extends beyond the boundary. The output image is slightly smaller than the input. Easy to implement. Smaller Output

الأسس الرياضية للتصفية المكانية

🔹 ما هو الـ Kernel (النواة / المرشح)؟

النواة أو الـ Kernel هي مصفوفة صغيرة (عادة 3×3 أو 5×5) من الأرقام تنزلق فوق الصورة. عند كل موضع، تُضرب قيم النواة مع قيم البيكسلات المجاورة في الصورة، ثم تُجمع النتائج للحصول على قيمة البيكسل الناتج.

🔹 معادلة التفاف ثنائية الأبعاد

g(x, y) = Σ Σ w(s,t) · f(x+s, y+t)

• f = الصورة الأصلية (Original Image)
• g = الصورة الناتجة (Output Image)
• w = معاملات النواة (Kernel Coefficients)
• (x,y) = إحداثيات البيكسل المستهدف
• (s,t) = إزاحات النواة

🔹 معالجة حواف الصورة (Edge Conditions)

  • Zero-Padding — الحشو بالأصفار: إضافة حد من القيمة 0 (بيكسلات سوداء) حول الصورة → الأكثر شيوعاً
  • Mirroring — الانعكاس: عكس بيكسلات الحافة للخارج → نتائج أفضل
  • Clipping — القطع: عدم حساب البيكسلات الحدودية → الصورة الناتجة أصغر

🎯 الفكرة المبسطة للـ Kernel

تخيل أنك تحمل نافذة صغيرة (النواة) وتمررها فوق كل نقطة في الصورة. في كل مكان تقف فيه، تنظر للبيكسلات القريبة وتحسب متوسطها الموزون (بحسب أوزان النواة) للحصول على قيمة جديدة للبيكسل.

Correlation vs Convolution

ℹ️ The Key Difference
Though they look almost identical in code, correlation and convolution differ in how the kernel is oriented before being applied. This distinction is mathematically critical.
📐 Correlation — الارتباط

Correlation slides the kernel directly over the image without any rotation. At each position, it computes the sum of element-wise products.

(f ⊛ g)(x, y) = Σs Σt g(s,t) · f(x+s, y+t)
  • The kernel is not rotated
  • Widely used for template matching (finding a small pattern in a larger image)
  • Used for feature detection
  • Most deep learning frameworks use correlation when they say "convolution"
🔄 Convolution — الالتفاف

Convolution flips (rotates) the kernel by 180° — both horizontally and vertically — before sliding it and computing the sum of products.

(f * g)(x, y) = Σs Σt g(s,t) · f(x-s, y-t)
  • The kernel is rotated 180° (flip horizontally then vertically, or equivalently rotate)
  • Is commutative: f * g = g * f
  • Is associative: (f * g) * h = f * (g * h)
  • Preferred in signal processing and mathematics
  • For symmetric kernels (like Gaussian), correlation = convolution
ℹ️ When does it matter?
The difference only matters for asymmetric kernels. For symmetric kernels (Gaussian, Laplacian), both give identical results.
Correlation = looking at your reflection in a mirror (same orientation). Convolution = looking at a page and its carbon copy (flipped). When the pattern is symmetric (like a circle), mirror and carbon copy look the same.

🔹 الارتباط (Correlation)

في الارتباط، نُحرك النواة مباشرة فوق الصورة بدون أي تدوير، ثم نحسب مجموع حاصل ضرب العناصر المتناظرة.

الفرق يظهر فقط مع النوى غير المتماثلة. أما النوى المتماثلة (مثل Gaussian أو Laplacian) فتُعطي نفس النتيجة في الحالتين.

Low-Pass Smoothing Operations — Linear Filters

ℹ️ What are Linear Filters?
Linear spatial filters compute the output pixel value as a weighted linear combination of neighborhood pixel values. They are excellent for low-pass smoothing (noise reduction, blurring).
Box Filter / Average Filter (مرشح المتوسط)
Replaces each pixel with the arithmetic mean of all pixels in its neighborhood. All weights are equal (1/N).

3×3 Box / Average Filter

All 9 coefficients = 1/9. Sum = 1 (normalized, so pixel values stay in valid range).

⚙️ How Box Filter Works
  1. Center the 3×3 kernel over a pixel P
  2. Read the 9 pixel values in the neighborhood (including P)
  3. Sum all 9 values, divide by 9
  4. Write the result as the new value of P in the output image
  5. Slide to the next pixel, repeat
⚠️ Disadvantage
The box filter blurs rapid transitions and edges aggressively. It treats all neighbors equally, so a bright edge pixel and a background pixel contribute equally — flattening sharp transitions into gradual ones.
Box filter = averaging your grades for a week. If you scored 100 on Monday but 30 every other day, your "weekly average" is dragged toward the middle. Sharp spikes get "diluted."
Gaussian Filter (المرشح الغاوسي)
Uses a 2D Gaussian function to assign weights — pixels closer to the center get higher weights, pixels farther away get lower weights.
G(x, y) = (1 / 2πσ²) × exp(−(x² + y²) / 2σ²)
σ (sigma) controls the spread — larger σ = wider blur | (x,y) = distance from center

المرشحات الخطية للتنعيم

🔹 المرشح الخطي (Linear Filter)

المرشح الخطي يحسب قيمة البيكسل الناتج كمجموع مرجح خطي لقيم البيكسلات المجاورة. هذا النوع ممتاز للتنعيم (Low-Pass Smoothing).

🔹 مرشح المتوسط (Box / Average Filter)

يستبدل كل بيكسل بالمتوسط الحسابي لجيرانه. جميع الأوزان متساوية (1/9 لنواة 3×3).
عيبه: يُشوّه الحواف بقوة لأنه لا يفرق بين البيكسلات القريبة والبعيدة.

🔹 المرشح الغاوسي (Gaussian Filter)

يستخدم الدالة الغاوسية ثنائية الأبعاد لتحديد الأوزان: البيكسلات الأقرب للمركز تأخذ وزناً أكبر.
σ (Sigma) = يتحكم في مدى الانتشار — كلما كبر σ زاد التمويه.
أفضل من مرشح المتوسط لأنه يحافظ على الحواف بشكل أفضل.

🔹 المصطلحات المهمة

  • Linear Filter — مرشح خطي: حساب موزون خطي للجيران
  • Box Filter — مرشح المتوسط: جميع الأوزان متساوية
  • Gaussian Filter — المرشح الغاوسي: أوزان تعتمد على المسافة (منحنى الجرس)
  • Sigma (σ) — الانحراف المعياري: يتحكم في مقدار التمويه
  • Normalization — التطبيع: قسمة مجموع النواة على 1 لتجنب تغيير السطوع الكلي
🎓 Exam Note
Common exam question: "Given a 3×3 image patch, apply a box filter and show the output." Also: "Why is Gaussian better than box for edge preservation?" Answer: Gaussian weights by distance → less distortion.

Non-Linear Order Statistics Filters

ℹ️ What makes them Non-Linear?
Non-linear filters do not compute a weighted sum. Instead, they rank/sort the neighborhood pixels and select one based on order statistics (median, max, min, midpoint).
📊 Median Filter (مرشح الوسيط)

Replaces each pixel with the median value of its neighborhood.

  1. Collect all pixel values in the kernel window (e.g., 9 values for 3×3)
  2. Sort them in ascending order
  3. Take the middle value (position 5 of 9 for 3×3)
  4. Write this as the new pixel value
✅ Why it's excellent
Median filter is excellent for salt-and-pepper noise (bipolar noise) — where some pixels are stuck at maximum (white = "salt") or minimum (black = "pepper"). A single extreme outlier cannot shift the median, so edges are preserved beautifully.
Imagine 9 students' test scores: 10, 85, 87, 88, 90, 91, 93, 94, 99. The score of 10 is an outlier (noise). Mean = ~82 (dragged down). Median = 90 (not affected by outlier). The median filter does the same for pixel noise.
⬆️ Max Filter (مرشح الحد الأقصى)

Replaces each pixel with the maximum value in its neighborhood.

  • Effect: Brightens the image, expands bright regions
  • Removes pepper noise (dark specks — value near 0 becomes replaced by a high max)
  • In morphology: called dilation
⬇️ Min Filter (مرشح الحد الأدنى)

Replaces each pixel with the minimum value in its neighborhood.

  • Effect: Darkens the image, expands dark regions
  • Removes salt noise (bright specks — value near 255 becomes replaced by a low min)
  • In morphology: called erosion
⚖️ Midpoint Filter (مرشح نقطة المنتصف)

Replaces each pixel with the average of the maximum and minimum values in the neighborhood:

Midpoint = (Max + Min) / 2
  • Combines properties of both max and min filters
  • Ideal for uniform noise (random values uniformly distributed)
  • Also works well for Gaussian noise
MaxMedMin Rule:
• Max → kills Pepper (dark noise) — "Max kills Pepper because Pepper is small"
• Min → kills Salt (bright noise) — "Min kills Salt because Salt is big"
• Median → kills both without blurring edges

المرشحات غير الخطية — إحصاءات الرتب

🔹 ما هي المرشحات غير الخطية؟

المرشحات غير الخطية لا تحسب مجموعاً مرجحاً. بدلاً من ذلك، تُرتّب قيم البيكسلات في النافذة (Neighborhood) وتختار واحدة منها بناءً على مرتبتها.

🔹 مرشح الوسيط (Median Filter)

يستبدل كل بيكسل بالوسيط (القيمة الوسطى بعد الترتيب).
مثال: [5, 3, 200, 8, 6] → بعد الترتيب: [3, 5, 6, 8, 200] → الوسيط = 6
ممتاز لإزالة ضوضاء الملح والفلفل (Salt-and-Pepper Noise) مع الحفاظ على الحواف.

🔹 مرشح الحد الأقصى (Max Filter)

يستبدل كل بيكسل بالقيمة الأعلى في جيرانه.
يُزيل: ضوضاء الفلفل (Pepper Noise) — البيكسلات السوداء غير المرغوبة.

🔹 مرشح الحد الأدنى (Min Filter)

يستبدل كل بيكسل بالقيمة الأدنى في جيرانه.
يُزيل: ضوضاء الملح (Salt Noise) — البيكسلات البيضاء غير المرغوبة.

🔹 مرشح نقطة المنتصف (Midpoint Filter)

الناتج = (القيمة القصوى + القيمة الدنيا) / 2
مثالي لـ: الضوضاء المنتظمة (Uniform Noise) والضوضاء الغاوسية (Gaussian Noise).

🔹 المصطلحات المهمة

  • Median Filter — مرشح الوسيط: القيمة الوسطى بعد الترتيب
  • Max Filter — يأخذ أعلى قيمة: يُزيل ضوضاء الفلفل
  • Min Filter — يأخذ أدنى قيمة: يُزيل ضوضاء الملح
  • Midpoint Filter — متوسط الحد الأقصى والأدنى
  • Salt-and-Pepper Noise — ضوضاء الملح والفلفل: بيكسلات عشوائية بيضاء وسوداء
  • Bipolar Noise — ضوضاء ثنائية القطب: نفس ضوضاء الملح والفلفل

✅ Step-by-Step Median Calculation

⚠️ Common Mistakes
  • Confusing which filter removes which noise: Max removes Pepper, Min removes Salt
  • Forgetting to sort values before finding median
  • Applying the wrong filter for the noise type (e.g., using Max for salt noise — will make it worse)

Non-Linear Restoration: Specialized Mean Filters

ℹ️ Why Different Means?
Different types of noise in images respond differently to different averaging methods. Standard arithmetic mean isn't always optimal. These specialized means target specific noise patterns.
➕ 1. Arithmetic Mean Filter
f̂(x,y) = (1/mn) Σ g(s,t)
  • Standard pixel averaging — sum all values, divide by count (mn = window area)
  • Effect: Smoothes local noise variations
  • Drawback: Blurs boundaries (edges) significantly
  • Best for: Mild Gaussian noise over uniform regions
✖️ 2. Geometric Mean Filter
f̂(x,y) = [Π g(s,t)]1/(mn)
  • Multiplies all neighborhood pixel values, then takes the (1/mn)-th power
  • Effect: Similar smoothing to arithmetic mean
  • Advantage: Retains image details better than arithmetic mean
  • Caveat: If any pixel = 0, the entire product = 0
Geometric mean is always ≤ arithmetic mean. For noise removal, smaller result = less over-smoothing.
🔁 3. Harmonic Mean Filter
f̂(x,y) = mn / Σ (1/g(s,t))
  • Computes the harmonic mean — (count) divided by (sum of reciprocals)
  • Excellent for: Removing salt noise (bright specks, high values)
  • Struggles with: Pepper noise (values near 0 cause division by zero)
🎛️ 4. Contra-Harmonic Mean Filter
f̂(x,y) = Σ g(s,t)Q+1 / Σ g(s,t)Q
Q is the order (power parameter)
  • Parameterized by Q (order) — a real number that controls behavior
  • Q > 0: Behaves like max → eliminates pepper noise
  • Q < 0: Behaves like min → eliminates salt noise
  • Q = 0: Reduces to arithmetic mean filter
  • Q = -1: Reduces to harmonic mean filter
The contra-harmonic filter is a unified framework — by changing Q, you can handle different noise types.
Contra-Harmonic Q Trick:
"Q Positive → removes Pepper (dark). Q Negative → removes sN (salt is white, negative kills white)."
Or: Q+ → kills dark; Q- → kills bright

Calculus of Image Sharpening — Derivatives

ℹ️ Why Derivatives?
Image sharpening = enhancing rapid changes in intensity. In calculus, derivatives measure rates of change. Therefore, spatial derivatives detect where intensity changes rapidly — i.e., edges.
📈 1st Derivative — Gradient Detection

The first derivative measures how much intensity changes as we move from one pixel to the next.

∂f/∂x ≈ f(x+1) − f(x)     (forward difference)
  • Produces wider edges (thick edge lines in output)
  • Responds strongly to step transitions (abrupt brightness changes)
  • Produces a non-zero response at ramps (gradual transitions) too
  • Always zero in constant regions
Like a car's speedometer — it tells you how fast you're going RIGHT NOW. At an edge, the "speed" of intensity change spikes.
📉 2nd Derivative — Acceleration Detection

The second derivative measures the rate of change of the rate of change — acceleration of intensity.

∂²f/∂x² ≈ f(x+1) − 2f(x) + f(x−1)
  • Produces finer, thinner edge lines
  • Responds strongly to fine details and isolated points
  • Zero-crossing property: the response crosses zero exactly at the edge location → precise edge localization
  • Zero in constant regions AND on linear ramps
  • Non-zero only at start and end of ramps (discontinuities in slope)
Like a car's acceleration dial — it's non-zero only when speed is changing. At a perfectly steady speed (ramp), acceleration = 0. Only at the start/stop of acceleration does the dial move.

1D Example: Derivatives Along a Row

Pixel row: [10, 10, 10, 50, 90, 90, 90, 90]

1st derivative: [0, 0, +40, +40, 0, 0, 0] → non-zero at ramp
2nd derivative: [0, 0, +40, 0, −40, 0, 0] → non-zero only at edges of ramp, crosses 0 at midpoint

تحسين الصور عبر المشتقات

🔹 لماذا نستخدم المشتقات؟

تحسين الحدة في الصور يعني تعزيز التغيرات السريعة في الشدة الضوئية. في حساب التفاضل، المشتقة تقيس معدل التغيير. لذلك، المشتقات المكانية تكتشف أين تتغير الشدة بسرعة، أي تكتشف الحواف.

🔹 المشتقة الأولى (First Derivative — Gradient)

تقيس مدى تغير الشدة من بيكسل للآخر.
∂f/∂x ≈ f(x+1) − f(x)
الخصائص:
• تنتج حواف أعرض
• تستجيب بقوة للتغيرات المفاجئة (Step Transitions)
• تساوي صفراً في المناطق الثابتة

🔹 المشتقة الثانية (Second Derivative — Acceleration)

تقيس معدل تغير المشتقة الأولى.
∂²f/∂x² ≈ f(x+1) − 2f(x) + f(x−1)
الخصائص:
• تنتج حواف أدق وأرفع
• خاصية عبور الصفر (Zero-Crossing): تعبر الصفر عند موقع الحافة بالضبط
• تساوي صفراً في المناطق الثابتة والمنحدرات الخطية

🔹 المصطلحات المهمة

  • First Derivative — المشتقة الأولى: معدل التغيير، يكتشف الحواف
  • Second Derivative — المشتقة الثانية: معدل تغير المعدل، أدق في تحديد الحواف
  • Zero-Crossing — عبور الصفر: ظاهرة المشتقة الثانية عند مواقع الحواف
  • Step Transition — تغير مفاجئ: حافة حادة في الصورة
  • Ramp — منحدر: تغير تدريجي في الشدة

The Laplacian Sharpening Operator

Laplacian (اللابلاسي)
The Laplacian is a second-order, isotropic (rotation-independent) derivative operator used for edge enhancement and image sharpening. It detects regions of rapid intensity change in all directions equally.

Mathematical Definition

∇²f = ∂²f/∂x² + ∂²f/∂y²
Laplacian = sum of second derivatives in x AND y directions

Expanding into discrete form:

∇²f(x,y) = f(x+1,y) + f(x−1,y) + f(x,y+1) + f(x,y−1) − 4·f(x,y)
The discrete Laplacian: sum of 4 neighbors minus 4 times the center

🔵 Isotropic Property

Laplacian = a "bump detector." On a flat surface (constant intensity), it returns 0. Where there's a "bump" (edge), it returns a large value. Adding the bump back to the image makes the edge stand out more.

Unsharp Masking Workflow

Unsharp Masking (إخفاء عدم الحدة)
A traditional image sharpening technique that works by subtracting a blurred version from the original to extract edge detail (the "mask"), then blending it back to create a sharpened result.

The 4-Step Workflow

1
Smooth the Image

Apply a low-pass filter (e.g., Gaussian blur) to create a blurred version f̄(x,y) of the original f(x,y). The blur removes all high-frequency edge detail.

2
Compute the Mask

Subtract the blurred image from the original: mask = f(x,y) − f̄(x,y). The result is the "unsharp mask" — it contains only the high-frequency edge/detail information that was removed by blurring.

3
Scale the Mask

Multiply the mask by a weight parameter k (also called the "boost factor"): k × mask. This controls how aggressively you sharpen. k=1 = standard unsharp masking. k>1 = high boost filter (extra sharpening). k between 0 and 1 = mild sharpening.

4
Final Blend

Add the scaled mask back onto the original: g(x,y) = f(x,y) + k × mask. The output has the smooth tonal structure of the original plus amplified edge detail.

Unsharp Masking:

mask(x,y) = f(x,y) − f̄(x,y)

g(x,y) = f(x,y) + k · mask(x,y)

g(x,y) = f(x,y) + k · [f(x,y) − f̄(x,y)]

g(x,y) = (1+k)·f(x,y) − k·f̄(x,y)
f = original | f̄ = blurred | k = boost weight | g = sharpened output
🚀 High Boost Filter
When k > 1, the technique becomes the High Boost Filter — it amplifies edge detail beyond the natural level, creating an exaggerated sharpness effect (sometimes used for artistic or diagnostic purposes).
⚠️ Over-sharpening
Too large a value of k causes halos (bright/dark rings around edges) and amplifies noise.
Unsharp masking is like editing a photo: blur it to find the "background," subtract the background to get only the "fine detail layer," amplify that detail, then add it back. This is exactly what professional photo editors do manually in Photoshop's "High Pass" workflow.
USM = Unsharp-Subtract-Multiply:
U = Unsharp (blur the original)
S = Subtract (mask = original − blurred)
M = Multiply and add back (sharpened = original + k×mask)

سير عمل إخفاء عدم الحدة (Unsharp Masking)

🔹 ما هو Unsharp Masking؟

تقنية تقليدية لتحسين حدة الصور. الفكرة: نُضبّب الصورة أولاً، ثم نطرح النسخة المضببة من الأصلية للحصول على قناع الحواف (Mask)، ثم نُضيف هذا القناع للصورة الأصلية لتحسين الحدة.

🔹 خطوات العمل الأربع

  • الخطوة 1: تنعيم الصورة — تطبيق مرشح منخفض (Low-Pass Filter) لإنشاء نسخة مضببة
  • الخطوة 2: حساب القناع — mask = الأصلية − المضببة (يحتوي فقط على معلومات الحواف)
  • الخطوة 3: ضبط الوزن — ضرب القناع بمعامل k للتحكم في درجة التحسين
  • الخطوة 4: الدمج النهائي — g = الأصلية + k × القناع

🔹 المعادلة الكاملة

g(x,y) = f(x,y) + k × [f(x,y) − f̄(x,y)]

حيث: f = الأصلية | f̄ = المضببة | k = معامل التقوية | g = الناتج المحسّن

🔹 فلتر التقوية العالية (High Boost Filter)

عندما k > 1: يصبح مرشح التقوية العالية (High Boost Filter) — تضخيم الحواف بشكل مبالغ.
تحذير: k كبير جداً يسبب هالات (Halos) حول الحواف ويُضخّم الضوضاء.

🔹 المصطلحات المهمة

  • Unsharp Masking — إخفاء عدم الحدة: تقنية التحسين بالطرح
  • Mask — القناع: الفرق بين الأصلية والمضببة = معلومات الحواف
  • Boost Factor (k) — معامل التقوية: يتحكم في درجة التحسين
  • High Boost Filter — مرشح التقوية العالية: عندما k > 1
  • Halo Effect — تأثير الهالة: تشويه يظهر عند k كبير جداً

Formula Derivation & Special Cases

General Formula: g = f + k(f − f̄)
g = f + kf − kf̄
g = (1+k)f − kf̄

Special Cases:
k = 0: g = f (no change, original returned)
k = 1: g = 2f − f̄ (standard unsharp masking)
k > 1: High Boost Filter (amplified sharpening)
k → ∞: approaches applying Laplacian sharpening

Worked Numerical Example

✅ Example

Original pixel f = 100

Blurred pixel f̄ = 95 (slightly smoothed)

Boost k = 2


mask = f − f̄ = 100 − 95 = 5

g = f + k × mask = 100 + 2 × 5 = 100 + 10 = 110

The edge pixel was brightened from 100 to 110, making it stand out more from its blurred background.

⚠️ Common Mistakes
  • Adding the original-blurred mask without scaling (k=0 gives no effect)
  • Using k that's too large → halos and noise amplification
  • Confusing Unsharp Masking with Laplacian sharpening: USM uses a blur-then-subtract pipeline; Laplacian directly uses 2nd derivative kernel

🟣 Short Answer Questions ▼
Explain the three methods for handling edge conditions when applying a spatial filter.
📖 Model Answer
1. Zero-Padding: A border of zero-value (black) pixels is added around the image. Simple and common; output keeps original size.

2. Mirroring: Edge pixels are reflected outward, creating a symmetric virtual border. Produces more natural-looking results since edge pixels aren't artificially zero.

3. Clipping: Pixels near the boundary where the kernel would extend outside are not computed. Output image is slightly smaller than input. No artificial values introduced.
Why is the median filter preferred over the mean filter for salt-and-pepper noise removal?
📖 Model Answer
The median filter sorts neighborhood values and selects the middle value. Extreme outliers (salt=255, pepper=0) end up at the extremes of the sorted list — not at the median position — so they are completely discarded. The mean filter, however, sums all values including the outliers, so a single extreme pixel (e.g., 255) dramatically shifts the average and corrupts the output. Additionally, the median filter does not blur edges because it selects an actual existing pixel value rather than computing a weighted average that doesn't exist in the image.
Describe the Unsharp Masking process and write its final formula.
📖 Model Answer
Steps: (1) Blur original f to get f̄. (2) Compute mask = f − f̄ (edge detail). (3) Scale mask by k. (4) Add to original: g = f + k·mask.

Combined formula: g(x,y) = f(x,y) + k·[f(x,y) − f̄(x,y)] = (1+k)·f(x,y) − k·f̄(x,y)

When k=1: standard unsharp masking. When k>1: High Boost Filter.
