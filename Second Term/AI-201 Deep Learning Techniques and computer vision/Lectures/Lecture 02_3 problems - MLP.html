1. The Backpropagation Algorithm — Big Picture

The Per-Epoch Loop: Forward Prop → Error → Back Prop → Update, Repeated for Every Pattern

🇬🇧 English Explanation
ENGLISH EXPLANATION

Training a Multi-Layer Perceptron (MLP) with backpropagation is an iterative loop repeated many times. One full pass through all training patterns is called an epoch. Inside a single epoch, the network processes each pattern one at a time, doing two things for each pattern: a Forward Prop step (compute outputs, measure error) and a Back Prop step (figure out who's to blame, nudge the weights).


Steps of a single epoch (for each pattern):

  1. Forward Prop — calculate net and o for every neuron except the input layer and bias neurons (input neurons just hold the raw feature values; bias neurons always output 1)
  2. Forward Prop — calculate the specific error for this single pattern (how wrong the network's output was for this one example)
  3. Back Prop — calculate delta (δ) for every neuron except the input layer and bias neurons — this is the "blame" signal
  4. Back Prop — calculate Δw (the weight change) for every variable weight, including the bias weights
  5. Back Prop — update every weight: w := w + Δw

After the end of the epoch (once every pattern has been processed once):

  1. Calculate the total error = the sum of all the specific errors collected from every pattern in this epoch
  2. Check the stopping condition (e.g. is the total error small enough? Have we hit the maximum number of epochs?)
  3. If the stopping condition is False (we're not done yet), run another epoch, starting from the weights we just ended up with
⚠️ Don't Confuse These Two "Errors"

The specific error (Err_p) belongs to a single pattern — it's recomputed fresh for every pattern during forward prop. The total error belongs to the whole epoch — it's the sum of all the specific errors, computed only once, after all patterns have been processed.

تدريب شبكة Multi-Layer Perceptron (MLP) بخوارزمية Backpropagation هو حلقة متكررة. الدورة الكاملة على جميع أمثلة التدريب تُسمى Epoch. داخل كل Epoch، تعالج الشبكة كل نمط (Pattern) على حدة، وتقوم بخطوتين لكل نمط: Forward Prop (حساب المخرجات وقياس الخطأ) ثم Back Prop (معرفة من المتسبب في الخطأ، وتعديل الأوزان بقدر صغير).


خطوات الـ Epoch الواحد (لكل نمط على حدة):

  1. Forward Prop — نحسب net و o لكل خلية عصبية باستثناء طبقة الإدخال وخلايا الـ bias (خلية الإدخال تحمل فقط قيمة الميزة الخام، وخلية الـ bias تُخرج دائمًا 1)
  2. Forward Prop — نحسب الخطأ الخاص بهذا النمط فقط (Err_p) — أي مقدار خطأ الشبكة في هذا المثال بالتحديد
  3. Back Prop — نحسب delta (δ) لكل خلية (باستثناء الإدخال والـ bias) — وهذا هو "توقيع اللوم" الذي يحدد مسؤولية كل خلية عن الخطأ
  4. Back Prop — نحسب Δw (مقدار التغيير) لكل وزن متغير، بما في ذلك أوزان الـ bias
  5. Back Prop — نُحدّث كل وزن: w := w + Δw

بعد انتهاء الـ Epoch (أي بعد معالجة كل الأنماط مرة واحدة):

  1. نحسب الخطأ الكلي (Total Error) = مجموع كل الأخطاء الخاصة (Err_p) لكل الأنماط في هذا الـ Epoch
  2. نتحقق من شرط التوقف (مثلًا: هل الخطأ الكلي أصبح صغيرًا كافيًا؟ هل بلغنا أقصى عدد من الـ Epochs؟)
  3. إذا كان شرط التوقف خاطئًا (لم ننته بعد)، نُشغّل Epoch آخر بدايةً من الأوزان الجديدة التي وصلنا إليها

النقطة المهمة التي يجب عدم الخلط فيها: الخطأ الخاص (Err_p) يخص نمطًا واحدًا فقط ويُعاد حسابه لكل نمط، أما الخطأ الكلي (Total Error) يخص الـ Epoch بالكامل ويُحسب مرة واحدة فقط بعد انتهاء جميع الأنماط.

💡 Analogy — Practicing a Skill

Think of learning to shoot a basketball free throw. Each attempt (a pattern) is: you try (forward prop), you see how far off you were from the hoop (specific error), you figure out what to adjust — elbow angle, wrist flick, knee bend (back prop / delta), and you slightly change your form (weight update). After a full practice session of many shots (an epoch), you tally up how bad your overall shooting was (total error) and decide whether you're good enough to stop practicing, or need another session (another epoch).

🧠 Memory Trick — The Backprop Cycle

"Fire, Feel, Fault, Fix"

Forward pass → Feel the error → Fault via delta (blame assignment) → Fix the weights

Repeat this 4-step cycle for every pattern, every epoch, until the stopping condition is met.

🎓 Exam / Interview Notes
  • 📌 One epoch = one full pass through ALL training patterns
  • 📌 Forward prop computes net & o (and error); back prop computes delta & Δw (and updates weights)
  • 📌 Weights update after every single pattern in this scheme (this is "online"/per-pattern update, not batch)
  • 📌 Bias neurons are never assigned a delta from "upstream" — but bias weights are still updated, using o_i = 1
  • 📌 Common exam Q: "What's the difference between specific error and total error?" → specific = per pattern, total = sum over the whole epoch

For each pattern: Forward Prop (compute net, o, specific error) then Back Prop (compute delta, Δw, update weights). After all patterns: total error = sum of specific errors, check the stopping condition, and repeat with another epoch if not yet satisfied.

2. The Core Formulas

net, o, delta (hidden vs. output), and the weight-update rule — the mathematical engine behind the loop

🇬🇧 English Explanation
ENGLISH EXPLANATION

Assume layer K is right before layer H, and either layer L is right after layer H, or H is itself the output layer. Every formula below is written from the point of view of a neuron h sitting in layer H.

1. Weighted Sum — net_h
neth = Σk∈K wk,h · ok

Every neuron feeding into h (every neuron k in the layer before h) sends its own output o_k, multiplied by the connecting weight w_k,h. Sum them all up — that raw, un-squashed total is net_h.

2. Activation — o_h
oh = fact(neth)   |   Default (sigmoid): oh = 1 / (1 + e−neth)

The activation function squashes net_h into the neuron's actual output o_h. Unless told otherwise, we default to the sigmoid function, which squashes any real number into the range (0, 1).

3. Delta for a HIDDEN Neuron
δh = f′act(neth) · Σl∈L δl · wh,l
Default (sigmoid): δh = oh(1 − oh) · Σl∈L δl · wh,l

If h is a hidden neuron, its delta depends entirely on the deltas of the neurons after it (layer L) — each weighted by the connection strength w_h,l — multiplied by the derivative of the activation function at h's own net. This is "blame flowing backward."

4. Delta for an OUTPUT Neuron
δh = f′act(neth) · (−∂Errp/∂yh)
Default (sigmoid, with Errp = ½ Σh∈H(th − yh)²):   δh = yh(1 − yh)(th − yh)

If h is an output neuron, there's no "layer after it" — instead its delta comes directly from how wrong its own prediction y_h was compared to the target t_h, again scaled by the activation derivative.

5. Weight Update Rule
Δwi,j = η · oi · δj   →   wi,j := wi,j + η · oi · δj

For every weight connecting neuron i to neuron j: the weight change is the learning rate η (how big a step we take) times o_i (what neuron i actually sent forward) times δ_j (how much neuron j is "to blame"). Special cases for o_i: if i is an input neuron, o_i = x_i (the raw feature value); if i is a bias neuron, o_i = 1 (bias neurons always output 1).

Symbol Glossary:

  • 🔹 net — the raw weighted sum entering a neuron, before activation
  • 🔹 o — the neuron's actual output after activation (o_i for a source neuron sending a signal forward)
  • 🔹 w — the weight (connection strength) between two neurons
  • 🔹 δ (delta) — the "blame signal" for a neuron: how much it contributed to the error, and in which direction to adjust
  • 🔹 η (eta) — the learning rate: a small constant controlling how big each weight update step is
  • 🔹 t — the target (desired/true) output for a training pattern
  • 🔹 y — the network's actual predicted output (same as "o" but specifically for an output neuron)
🇸🇦 الشرح بالعربي

لنفترض أن الطبقة K تسبق مباشرة الطبقة H، وأن الطبقة L تأتي بعد H مباشرة، أو أن H نفسها هي طبقة الإخراج. كل الصيغ التالية مكتوبة من منظور خلية عصبية واحدة اسمها h في الطبقة H.


١. المجموع الموزون net_h:

كل خلية k في الطبقة السابقة تُرسل مخرجها o_k مضروبًا في وزن الوصلة w_k,h. نجمع كل هذه القيم فنحصل على net_h — وهو المجموع الخام قبل أي تفعيل.


٢. التفعيل o_h:

نُمرر net_h على دالة التفعيل لنحصل على المخرج الفعلي o_h. الافتراضي هو دالة Sigmoid: o_h = 1/(1+e^-net_h) والتي تضغط أي رقم ليصبح بين 0 و 1.


٣. delta للخلية المخفية (Hidden):

إذا كانت h خلية مخفية، فإن قيمة δ_h تعتمد على "اللوم" القادم من الخلايا التالية لها (الطبقة L)، كل واحدة منها مضروبة في وزن الوصلة معها، ثم كل هذا مضروب في مشتقة دالة التفعيل. الصيغة الافتراضية لـ Sigmoid: δ_h = o_h(1-o_h) · Σ δ_l·w_h,l.


٤. delta لخلية الإخراج (Output):

إذا كانت h خلية إخراج، فلا توجد طبقة بعدها — بدلًا من ذلك تعتمد δ_h مباشرة على مقدار خطأ تنبؤها y_h مقارنة بالهدف t_h. الصيغة الافتراضية (مع دالة الخطأ Err_p = ½Σ(t_h-y_h)²): δ_h = y_h(1-y_h)(t_h-y_h).


٥. قاعدة تحديث الأوزان:

Δw_i,j = η·o_i·δ_j ثم w_i,j := w_i,j + Δw_i,j. أي أن التغيير في الوزن بين خلية i وخلية j = معدل التعلم η × ما أرسلته الخلية i فعليًا × مقدار "لوم" الخلية j. ملاحظة مهمة: إذا كانت i خلية إدخال، فإن o_i = x_i (قيمة الميزة الخام)؛ وإذا كانت i خلية bias، فإن o_i = 1 دائمًا.


قاموس الرموز:

  • net — المجموع الموزون الخام قبل التفعيل
  • o — مخرج الخلية الفعلي بعد التفعيل
  • w (weight) — قوة الوصلة بين خليتين
  • δ (delta) — "توقيع اللوم"، مقدار مساهمة الخلية في الخطأ واتجاه التصحيح
  • η (eta) — معدل التعلم، رقم صغير يتحكم في حجم كل خطوة تحديث
  • t (target) — القيمة الصحيحة/المرغوبة للناتج
  • y — التنبؤ الفعلي لخلية الإخراج
💡 Analogy — Blame Assignment

Backpropagation is fundamentally a "blame assignment" algorithm. When the final answer is wrong, delta at the output neuron measures directly how wrong it was. Then, working backward layer by layer, each hidden neuron asks: "of all the neurons I feed into, how much did MY signal contribute to their mistakes?" — and gets assigned a proportional share of the blame (weighted by the connection strength). Once every neuron knows its share of the blame, every weight gets nudged a tiny bit in the direction that would have reduced that blame.

⚠️ Warning from the Source Material

These clean formulas — o_h(1-o_h)·Σδ_l·w_h,l for hidden deltas and y_h(1-y_h)(t_h-y_h) for output deltas — are only valid because we assumed the sigmoid activation function AND the ½Σ(t-y)² (sum-of-squared-errors) error function.

If you use a different activation function or a different error function, you must re-derive the derivatives yourself: specifically, you must recompute f′_act(net_h) · (−∂Err_p/∂y_h) from scratch for the new functions. The general delta formulas (with the derivative terms left symbolic) always hold — only the "default" plugged-in simplifications change.

🎓 Exam / Interview Notes
  • 📌 Know which delta formula applies where: hidden neuron delta looks forward to layer L; output neuron delta looks at the error function directly
  • 📌 The sigmoid derivative is famously simple: f′(net) = o(1-o) — memorize this
  • 📌 Δw always has the same shape: η · (sender's output) · (receiver's delta)
  • 📌 If activation ≠ sigmoid or error ≠ sum-of-squares, the "default" simplified deltas do NOT apply — you must re-derive

net_h = Σw·o, o_h = sigmoid(net_h). Hidden delta looks forward: o_h(1-o_h)·Σδ_l·w_h,l. Output delta compares to target: y_h(1-y_h)(t_h-y_h). Weight update: Δw = η·o_i·δ_j. Different activation/error function → re-derive the deltas.

3. The Network Setup for This Example

A Tiny 2→2→1 MLP Learning an XOR-Like Truth Table

🇬🇧 English Explanation
ENGLISH EXPLANATION

The worked example uses the smallest possible MLP that can demonstrate the full algorithm: 2 input neurons (x1, x2), 2 hidden neurons (numbered 3 and 4), and 1 output neuron (numbered 5). The network is fully connected — every input connects to every hidden neuron, and every hidden neuron connects to the output neuron. Each non-input neuron (3, 4, and 5) also receives a connection from a bias neuron that always outputs 1.

The training data — an XOR-like truth table:

x1x2t (target)
000
011
101
110

This is exactly the XOR logic function — a classic example precisely because it is not linearly separable, which is why a single-layer perceptron cannot learn it but a hidden layer can.

يستخدم المثال المحلول أصغر شبكة MLP ممكنة تُظهر الخوارزمية كاملة: خليتا إدخال (x1, x2)، خليتان مخفيتان (رقم 3 ورقم 4)، وخلية إخراج واحدة (رقم 5). الشبكة متصلة بالكامل (fully connected) — كل خلية إدخال متصلة بكل خلية مخفية، وكل خلية مخفية متصلة بخلية الإخراج. كل خلية غير إدخال (3، 4، 5) تستقبل أيضًا وصلة من خلية bias تُخرج دائمًا القيمة 1.


بيانات التدريب — جدول شبيه بـ XOR:

النمط (0,0)→0، النمط (0,1)→1، النمط (1,0)→1، النمط (1,1)→0. هذا هو تمامًا منطق XOR — وهو مثال كلاسيكي لأنه غير قابل للفصل خطيًا (not linearly separable)، ولهذا السبب لا تستطيع شبكة بدون طبقة مخفية تعلّمه، بينما شبكة بطبقة مخفية تستطيع.


الأوزان الابتدائية ومعدل التعلم:

w13=0.3, w23=-0.1, wb3=0.2 (توصل الطبقة إلى الخلية 3) — w14=-0.2, w24=0.2, wb4=-0.3 (توصل إلى الخلية 4) — w35=0.4, w45=-0.2, wb5=0.4 (توصل الطبقة المخفية إلى الخلية 5). ومعدل التعلم η = 0.3.

💡 Why a Hidden Layer Is Necessary Here

XOR cannot be separated by a single straight line — plot the 4 points (0,0), (0,1), (1,0), (1,1) with their labels and you'll see the "1" points and "0" points sit diagonally opposite each other. A single-layer perceptron can only draw one straight decision boundary, so it fails on XOR. The hidden layer (neurons 3 and 4) lets the network combine two different linear boundaries into a non-linear one that can correctly separate the classes.

2 inputs → 2 hidden neurons (3, 4) → 1 output neuron (5), fully connected, with a bias unit (output = 1) feeding every non-input neuron. Task: learn the XOR truth table. Initial weights given; η = 0.3.

4. Pattern 1 Fully Worked (Epoch 1)

x1 = 0, x2 = 0, t = 0 — The Source Worksheet's Own Fully-Solved Example

🇬🇧 English Explanation
ENGLISH EXPLANATION

This is the pattern the original worksheet solves completely — the arithmetic below reproduces it exactly.

Forward Prop

  1. net3 = w13·x1 + w23·x2 + wb3 = 0.3·0 − 0.1·0 + 0.2 = 0.2000
  2. o3 = 1/(1+e−net3) = 1/(1+e−0.2) = 0.5498
  3. net4 = w14·x1 + w24·x2 + wb4 = −0.2·0 + 0.2·0 − 0.3 = −0.3000
  4. o4 = 1/(1+e−net4) = 1/(1+e0.3) = 0.4256
  5. net5 = w35·o3 + w45·o4 + wb5 = 0.4·0.5498 − 0.2·0.4256 + 0.4 = 0.5348
  6. y = 1/(1+e−net5) = 1/(1+e−0.5348) = 0.6306
  7. Err_p1 = 0.5·(t − y)² = 0.5·(0 − 0.6306)² = 0.1988

Back Prop — Step 1: Finding Delta

  1. δ5 = y(1−y)(t−y) = 0.6306·(1−0.6306)·(0−0.6306) = −0.1469
  2. δ3 = o3(1−o3)·δ5·w35 = 0.5498·(1−0.5498)·(−0.1469)·0.4 = −0.0145
  3. δ4 = o4(1−o4)·δ5·w45 = 0.4256·(1−0.4256)·(−0.1469)·(−0.2) = 0.0072

Back Prop — Step 2: Finding New Weights (η = 0.3)

  1. w35 := w35 + η·o3·δ5 = 0.4 + 0.3·0.5498·(−0.1469) = 0.3758
  2. w45 := w45 + η·o4·δ5 = −0.2 + 0.3·0.4256·(−0.1469) = −0.2188
  3. wb5 := wb5 + η·1·δ5 = 0.4 + 0.3·1·(−0.1469) = 0.3559
  4. w14 := w14 + η·x1·δ4 = −0.2 + 0.3·0·0.0072 = −0.2000
  5. w24 := w24 + η·x2·δ4 = 0.2 + 0.3·0·0.0072 = 0.2000
  6. wb4 := wb4 + η·1·δ4 = −0.3 + 0.3·1·0.0072 = −0.2978
  7. w13 := w13 + η·x1·δ3 = 0.3 + 0.3·0·(−0.0145) = 0.3000
  8. w23 := w23 + η·x2·δ3 = −0.1 + 0.3·0·(−0.0145) = −0.1000
  9. wb3 := wb3 + η·1·δ3 = 0.2 + 0.3·1·(−0.0145) = 0.1956

Notice that w13, w23, w14, w24 didn't move at all — because x1 = 0 and x2 = 0 for this pattern, so the input-side weight updates are multiplied by zero. Only the bias weights (wb3, wb4) and the hidden-to-output weights (w35, w45, wb5) changed.

🇬🇧 English Explanation
ENGLISH EXPLANATION — MODEL SOLUTION

🧪 Full Quiz Bank

Multiple Choice and Short Answer Questions on MLP Backpropagation

🔵 Multiple Choice Questions

Q1. Within a single epoch, what is the correct order of operations for one pattern?

  • A) Back prop, then forward prop
  • B) Forward prop (net, o, specific error), then back prop (delta, Δw, update)
  • C) Update weights, then compute error
  • D) Compute total error, then forward prop
✅ Answer: B — Forward prop must happen first to produce the outputs and the specific error; back prop then uses those values to compute delta and update weights.

Q2. Which formula correctly computes delta for a HIDDEN neuron h under the sigmoid default?

  • A) δ_h = y_h(1-y_h)(t_h-y_h)
  • B) δ_h = o_h(1-o_h)·Σ δ_l · w_h,l
  • C) δ_h = η · o_h · δ_l
  • D) δ_h = net_h · o_h
✅ Answer: B — Hidden neuron delta sums the "blame" flowing back from all neurons in the next layer L, weighted by the connecting weights, times the sigmoid derivative o_h(1-o_h). Option A is the OUTPUT neuron formula.

Q3. Which formula correctly computes delta for an OUTPUT neuron h under the sigmoid + sum-of-squares default?

  • A) δ_h = o_h(1-o_h)·Σ δ_l · w_h,l
  • B) δ_h = y_h(1-y_h)(t_h-y_h)
  • C) δ_h = w_h,l · net_h
  • D) δ_h = Err_p / η
✅ Answer: B — Output neuron delta compares the prediction y_h directly to the target t_h, scaled by the sigmoid derivative y_h(1-y_h). Option A is the HIDDEN neuron formula (a very common exam trick).

Q4. In the weight update rule Δw_i,j = η·o_i·δ_j, what is o_i if neuron i is a bias neuron?

  • A) o_i = x_i
  • B) o_i = 1
  • C) o_i = 0
  • D) o_i = δ_j
✅ Answer: B — A bias neuron always outputs 1. If i were an input neuron instead, o_i = x_i (the raw feature value).

Q5. In the worked Pattern 1 (x1=0, x2=0, t=0), why did w13, w23, w14, and w24 NOT change after the update?

  • A) Because delta was zero for all hidden neurons
  • B) Because x1 = 0 and x2 = 0, so Δw = η·x·δ = 0 for those input-connected weights
  • C) Because the learning rate was zero
  • D) Because those weights are frozen by design
✅ Answer: B — Δw_i,j = η·o_i·δ_j, and for input neurons o_i = x_i. Since x1=x2=0, any weight connected directly to x1 or x2 gets multiplied by zero, leaving it unchanged — even though delta itself was non-zero.

Q6. What is the "total error" at the end of an epoch?

  • A) The error of the last pattern processed
  • B) The sum of the specific errors (Err_p) from every pattern processed in that epoch
  • C) The average of all delta values
  • D) The learning rate times the number of patterns
✅ Answer: B — Total error = Err_p1 + Err_p2 + ... + Err_pN, summed across all N patterns in the epoch. For this example: 0.1988+0.0759+0.0670+0.2040 = 0.5457.

Q7. If a different (non-sigmoid) activation function is used, what must be re-derived?

  • A) The learning rate η
  • B) The truth table
  • C) The derivative term f′_act(net_h)·(−∂Err_p/∂y_h), and hence the delta formulas
  • D) Nothing — the formulas are universal
✅ Answer: C — The "default" simplified deltas (o(1-o)·... and y(1-y)(t-y)) only hold for sigmoid + sum-of-squares error. Any other activation or error function requires recomputing the derivative terms from scratch.

Q8. Why is XOR a good demonstration problem for a hidden-layer MLP?

  • A) It has the largest possible dataset
  • B) It is not linearly separable, so it requires a hidden layer to solve
