1. Computer Vision in the AI Ecosystem

Positioning CV within AI, ML, and Deep Learning — the Nested Fields Diagram

📋 Original Slide Content

🇬🇧 English Explanation
ENGLISH EXPLANATION

Computer Vision (CV) is a field of Artificial Intelligence that enables computers to "see" and understand digital images and videos — much like how the human visual cortex processes what our eyes capture.


Think of it as a nested set of Russian dolls:

🔵 Artificial Intelligence (AI) — the outermost shell; the broadest concept of making machines intelligent

🟢 Machine Learning (ML) — inside AI; machines learn from data instead of explicit rules

🟣 Deep Learning (DL) — inside ML; uses multi-layer neural networks inspired by the brain

👁️ Computer Vision (CV) — a specialized domain that uses DL to process visual data

CV sits at the intersection of three fields:

  • 🔬 Digital Signal Processing (DSP) — the math behind manipulating image data (pixel values, frequency transforms)
  • 🧠 Neurological Simulation — Convolutional Neural Networks (CNNs) are modeled after how the visual cortex neurons fire
  • 📐 Mathematical Optimization — gradient descent and backpropagation train the models

CV interfaces with:

  • Robotics — robots use CV to navigate and manipulate objects
  • Autonomous Systems — self-driving cars read road signs, detect pedestrians
  • NLP (Natural Language Processing) — reading text in images (OCR), image captioning
⚠️ Common Misconception

CV ≠ Image Processing. Traditional image processing applies fixed mathematical filters (blur, sharpen). CV adds semantic understanding — "this is a cat, not a dog."

2. Traditional Image Processing Pipelines

Mathematical Binary Heuristics — Before Deep Neural Networks

📋 Original Slide Content
  • Binarization: Maps an RGB channel to a high-contrast binary black-and-white grid.
  • Connected Components: Groups adjacent pixel clusters using coordinate connectivity rules (4-way or 8-way).
  • Feature Counting: Measures distinct contours and segmented elements to count geometric shapes directly.
🇬🇧 English Explanation
ENGLISH EXPLANATION

Before deep learning dominated, engineers used rule-based pixel transformations to extract information from images. Here are the three key traditional techniques:


1. Binarization (Thresholding)

Converts a color (RGB) or grayscale image into a pure black-and-white (binary) image. Each pixel becomes either 0 (black) or 1 (white) based on a threshold value T.

If pixel_value ≥ T → White (1)  |  If pixel_value < T → Black (0)

Why useful? Removes noise, isolates objects from backgrounds. Used in document scanning, QR code reading.

2. Connected Components Analysis

After binarization, groups of white pixels that are "touching" each other are labeled as belonging to the same component (object). Two types of connectivity:

4-Way Connectivity

A pixel is connected to its 4 direct neighbors: up, down, left, right. Diagonal neighbors do NOT count.

8-Way Connectivity

A pixel is connected to all 8 neighbors including diagonals. More permissive, better for curved shapes.

3. Feature Counting

After labeling connected components, the system counts distinct blobs/contours. Example: count how many coins are in a photo, count how many cells in a microscope slide. Measures geometric properties: area, perimeter, circularity.

The Classic Pipeline Step-by-Step:

  1. Load color image (RGB, 3 channels)
  2. Convert to grayscale (1 channel, 0–255 intensity)
  3. Apply threshold → binary image (0 or 1)
  4. Find connected components (label each blob)
  5. Count/measure components to extract features
🇸🇦 الشرح بالعربي

قبل ظهور التعلم العميق، كان علماء الحاسوب يستخدمون تحويلات رياضية صارمة على البيكسل لاستخراج المعلومات من الصور:


١. التحويل الثنائي (Binarization):

تحويل الصورة الملونة إلى صورة ثنائية (أبيض وأسود فقط) باستخدام عتبة T. إذا كان البيكسل أفتح من T → أبيض، وإذا كان أغمق → أسود. مثال: تحويل صورة فاتورة ورقية إلى نص واضح قبل قراءتها.


٢. المكونات المترابطة (Connected Components):

بعد التحويل الثنائي، يتم تجميع البيكسلات البيضاء المتجاورة معًا في "كتل" أو "مكونات". اتصال رباعي = يحسب 4 جيران فقط (فوق-تحت-يسار-يمين). اتصال ثماني = يحسب 8 جيران (يشمل الأركون القطرية أيضًا).


٣. عد الأشكال (Feature Counting):

بعد تحديد المكونات، نحسبها ونقيس خصائصها (المساحة، المحيط، الشكل الدائري). مثال: عد عدد العملات في صورة، أو عد خلايا الدم في مجهر.


المصطلحات المهمة:

  • Binarization (التثنيئة/التحويل الثنائي) — تحويل لأبيض وأسود
  • Threshold (العتبة) — القيمة الحدية للتمييز
  • Connected Components (المكونات المترابطة) — تجميع البيكسلات المتجاورة
  • Contour (المحيط/الحافة) — حدود الشكل الهندسي
  • 4-way / 8-way Connectivity (الاتصال الرباعي/الثماني)
💡 Practical Example — Counting Coins
  1. Take a photo of 5 coins on a white table
  2. Convert to grayscale (coins are darker than white background)
  3. Apply threshold: pixels below 128 → black (coins), above → white (background)
  4. Find connected components: 5 distinct dark blobs labeled
  5. Count = 5 ✓

This exact approach was used in early industrial inspection systems to count manufactured parts on conveyor belts.

🚫 Common Mistakes
  • ❌ Confusing 4-way vs 8-way connectivity — 8-way is more common in practice
  • ❌ Forgetting that threshold selection is critical — wrong T ruins results
  • ❌ Thinking traditional processing is "obsolete" — it's still used when speed > accuracy
🎓 Exam Notes
  • 📌 Draw the pipeline: RGB → Grayscale → Binary → Connected Components → Count
  • 📌 Know the binarization formula: pixel ≥ T → 1, else → 0
  • 📌 Difference between 4-way and 8-way connectivity
  • 📌 Limitation: works only for simple, well-separated objects; fails on complex scenes

Traditional CV: Binarization (pixel → 0 or 1) → Connected Components (group adjacent pixels, 4-way or 8-way) → Feature Counting (count/measure blobs). Pre-DL pipeline, still used for simple/fast tasks.

3. Machine Learning vs. Deep Learning Feature Pipelines

The Evolution from Hand-Crafted Features to End-to-End Learning

📋 Original Slide Content
  • Classical ML: Requires engineers to hand-craft visual descriptor matrices (HOG, SIFT) before classifying with SVMs.
  • Deep Learning: Uses convolutional layer hierarchies to automatically detect raw edges, midpoint textures, and global semantic shapes.
  • Unified Grid: Merges features and classifier layers into an end-to-end backpropagation loop.
🇬🇧 English Explanation
ENGLISH EXPLANATION

This slide explains the paradigm shift from classical ML to Deep Learning — arguably the most important concept in modern CV.


Classical ML Pipeline

  • Human expert manually designs feature extractors
  • Popular descriptors: HOG (Histogram of Oriented Gradients), SIFT (Scale-Invariant Feature Transform)
  • Features fed into a classifier like SVM (Support Vector Machine)
  • Two separate stages: Feature Extraction + Classification
  • Time-consuming, domain-expert required

Deep Learning Pipeline

  • CNN automatically learns features from raw pixels
  • Layer 1: detects edges
  • Layer 2: detects textures/patterns
  • Layer 3+: detects semantic shapes (eyes, wheels)
  • Feature extraction + classification = one unified model
  • End-to-end training via backpropagation

Key Abbreviations Explained:

HOG — Histogram of Oriented Gradients

Counts how many edges point in each direction within small cells of an image. Creates a "fingerprint" of shapes. Very effective for detecting people (pedestrian detection).

SIFT — Scale-Invariant Feature Transform

Finds distinctive "keypoints" in images that remain recognizable even when the image is zoomed in/out, rotated, or slightly blurred. Used in image stitching (panoramas).

SVM — Support Vector Machine

A classical ML classifier that finds the optimal "hyperplane" separating two classes of data. Works well with hand-crafted feature vectors.

CNN — Convolutional Neural Network

A deep neural network with convolutional layers that slide small filters over an image to detect patterns. The backbone of modern CV.

Backpropagation

The algorithm used to train neural networks. Calculates how much each weight contributed to the error, then adjusts weights to reduce that error. Flows "backwards" from output to input.

🇸🇦 الشرح بالعربي

هذه الشريحة تشرح التحول الجذري في طريقة تصميم أنظمة رؤية الحاسوب:


التعلم الآلي التقليدي (Classical ML):

المهندس البشري يُصمم يدويًا خوارزميات لاستخراج الميزات (مثل HOG وSIFT)، ثم يُمرر هذه الميزات إلى مُصنِّف مثل SVM. المشكلة: يتطلب خبراء بشريين، وكل مشكلة تحتاج تصميمًا جديدًا.


التعلم العميق (Deep Learning):

الشبكة العصبية الالتفافية (CNN) تتعلم تلقائيًا من البيانات الخام: الطبقة الأولى تكتشف الحواف، الطبقة الثانية تكتشف الأنماط والملمس، الطبقات العليا تكتشف الأشكال الكاملة (وجه، سيارة...). كل شيء في نموذج واحد متكامل.


المصطلحات:

  • HOG (مدرج التوجيهات التدريجية) — استخراج ميزات الشكل يدويًا
  • SIFT (تحويل الميزات الثابتة بالحجم) — استخراج نقاط مميزة في الصورة
  • SVM (آلة المتجهات الداعمة) — مُصنِّف للتعلم الآلي الكلاسيكي
  • CNN (شبكة عصبية التفافية) — العمود الفقري لرؤية الحاسوب الحديثة
  • Backpropagation (الانتشار العكسي) — خوارزمية تدريب الشبكات العصبية
  • End-to-End Learning (التعلم من النهاية إلى النهاية) — نموذج واحد يفعل كل شيء
💡 Analogy — The Cat Identification Example (Referenced in Slide)

Classical ML approach to classify "Is this a cat?":

  1. Human engineer writes code: "look for pointy ears, whiskers, slanted eyes"
  2. HOG descriptors extract these shape features as number vectors
  3. SVM classifier: if features match cat template → "cat"

Deep Learning approach:

  1. Show CNN 1 million cat/non-cat labeled photos
  2. CNN automatically discovers that cats have pointy ears, round eyes, whiskers
  3. No human feature engineering needed
🧠 Memory Trick — HOG & SIFT

HOG = "How Objects Generally look" (counts edge directions)

SIFT = "Same Image, Flexible Transformation" (scale/rotation invariant)

🎓 Exam Notes
  • 📌 Key difference: Classical ML = hand-crafted features + separate classifier. DL = automatic features + unified model
  • 📌 HOG and SIFT are hand-crafted feature extractors used in classical CV
  • 📌 CNNs learn hierarchically: edges → textures → shapes → semantics
  • 📌 "End-to-end" = features and classification are learned together in one model
  • 📌 Backpropagation is the training algorithm for neural networks

Classical ML: Human designs features (HOG/SIFT) → SVM classifies. Deep Learning: CNN automatically learns features from pixels. DL is end-to-end — one unified backprop loop. No human feature engineering required.

4. Classification, Detection & Segmentation

Understanding Spatial Resolution in Computer Vision Tasks

📋 Original Slide Content
  • Image Classification: Determines global image semantic categories (e.g., predicting a single "cat" label).
  • Object Detection: Draws bounding coordinates around individual visual targets.
  • Semantic Segmentation: Assigns labels to every pixel to outline clean silhouettes.
🇬🇧 English Explanation
ENGLISH EXPLANATION

These three tasks form a spectrum of spatial precision. Each provides more detailed localization of objects in an image:


🏷️ Image Classification — "What is in this image?"

The simplest CV task. The model looks at the entire image and outputs one label (or a probability distribution over labels). No location information.

Output: "This image contains a cat" (90% confidence)

Example models: ResNet, VGG, EfficientNet

Real-world use: Photo app organizing your gallery by subject

📦 Object Detection — "What AND Where?"

Finds objects AND draws a bounding box (rectangle) around each one. Can detect multiple objects of different classes in one image.

Output: [cat: (x=100, y=200, w=150, h=130, conf=0.92)] [dog: (x=300, y=180, w=120, h=140, conf=0.88)]

Example models: YOLO (You Only Look Once), Faster R-CNN, SSD

Real-world use: Traffic cameras detecting vehicles, security cameras flagging intruders

🎭 Semantic Segmentation — "Which pixel belongs to what?"

The most precise task. Assigns a class label to every single pixel in the image. Creates a colored mask showing exact silhouettes.

Types:

  • Semantic Segmentation: All cats get the same "cat" label (doesn't distinguish individual instances)
  • Instance Segmentation: Cat1 gets a different mask from Cat2
  • Panoptic Segmentation: Combines both

Example models: U-Net (medical), Mask R-CNN, DeepLab

Real-world use: Medical MRI segmentation, autonomous car understanding road vs. sidewalk vs. pedestrian


Granularity Spectrum:

Classification
Image-level label → more precise → Detection
Bounding boxes → more precise → Segmentation
Pixel-level masks
🇸🇦 الشرح بالعربي

هذه المهام الثلاث تمثل مستويات متزايدة من الدقة المكانية في فهم الصورة:


١. تصنيف الصورة (Image Classification):

أبسط مهمة: النموذج ينظر للصورة كاملة ويقول "هذه صورة قطة". لا يعرف أين القطة في الصورة، يقول فقط ما الموجود.


٢. اكتشاف الأجسام (Object Detection):

أكثر دقة: يجد الجسم ويرسم حوله مستطيلًا (bounding box). يستطيع اكتشاف أجسام متعددة مختلفة في نفس الصورة ويحدد موقع كل منها.


٣. التجزئة الدلالية (Semantic Segmentation):

الأكثر دقة: يُعطي تصنيفًا لكل بيكسل في الصورة. مثال: كل بيكسل يرى إما "قطة" أو "أرض" أو "خلفية". يُنتج قناعًا ملونًا بدلاً من مستطيل.


المصطلحات:

  • Image Classification (تصنيف الصورة) — تسمية الصورة بأكملها
  • Object Detection (كشف الأجسام) — تحديد الأجسام ورسم مستطيلات حولها
  • Bounding Box (صندوق الإحاطة) — المستطيل المرسوم حول الجسم
  • Semantic Segmentation (التجزئة الدلالية) — تصنيف على مستوى البيكسل
  • Pixel-Level Mask (قناع على مستوى البيكسل) — صورة ملونة تُظهر تصنيف كل نقطة
  • YOLO (تنظر مرة واحدة فقط) — نموذج كشف أجسام سريع جدًا
💡 Example — Same Image, Three Tasks

Input: Photo of a street scene with 2 people, 1 car, 1 traffic light


🏷️ Classification output: "Street scene" (one label for the whole image)

📦 Detection output:

Person 1: [x:45, y:120, w:80, h:200] confidence: 0.97
Person 2: [x:350, y:110, w:75, h:190] confidence: 0.94
Car:      [x:200, y:250, w:300, h:150] confidence: 0.99
Traffic Light: [x:500, y:50, w:30, h:80] confidence: 0.91

🎭 Segmentation output: Each pixel colored by class — red=person, blue=car, green=traffic light, gray=road, white=sky

⚠️ Important Note — Instance vs Semantic Segmentation

The slide says "Semantic Segmentation" but it's important to know:

  • 🔷 Semantic Segmentation: Pixel-level labels, but two people both labeled "person" (same color)
  • 🔷 Instance Segmentation: Person 1 = different color from Person 2 (each instance distinct)
🎓 Exam Notes
  • 📌 Know the granularity spectrum: Classification → Detection → Segmentation
  • 📌 Classification = image-level label, no location
  • 📌 Detection = bounding boxes + class labels + confidence scores
  • 📌 Segmentation = pixel-level classification
  • 📌 YOLO = popular real-time object detection model
  • 📌 U-Net = popular segmentation model for medical images

Classification: whole-image label. Detection: bounding boxes around each object. Segmentation: label every pixel. Increasing spatial precision from left to right.

5. Multi-Object Video Tracking

Temporal Association Over Time — Maintaining Identities Across Frames

📋 Original Slide Content
  • Temporal ID Association: Connects bounding coordinates dynamically across changing frames.
  • Surveillance Monitoring: Vital for counting people, analyzing traffic, and detecting anomalies.
  • Algorithms: Combines Kalman Filters, Hungarian matching, and Deep SORT feature networks.
🇬🇧 English Explanation
ENGLISH EXPLANATION

Object Tracking adds the temporal dimension to object detection. While detection finds objects in a single frame, tracking follows the same object across consecutive video frames, maintaining a consistent identity.


The Core Problem: In frame 1, you detect Person A and Person B. In frame 2, they've moved. How do you know which detection in frame 2 corresponds to Person A and which to Person B? That's the "association problem."


Key Algorithms:

Kalman Filter

A mathematical prediction algorithm. Given an object's current position and velocity, it predicts where the object will be in the next frame even before we detect it. Handles missed detections (occlusion).

Analogy: Like predicting where a ball will land based on its current trajectory and speed.

Hungarian Algorithm (Hungarian Matching)

An optimization algorithm that solves the "assignment problem": given N predicted positions (from Kalman) and M new detections, find the optimal one-to-one matching that minimizes total distance. Like assigning waiters to tables most efficiently.

Deep SORT (Simple Online and Realtime Tracking with Deep appearance)

Extends SORT by adding a deep neural network that extracts "appearance features" (what the person looks like) alongside position features. If two people cross paths (occlusion), appearance features help re-identify the correct one.


Applications:

  • 🏪 Retail analytics: Count customers who entered a store
  • 🚦 Traffic analysis: Count vehicles by type, measure speed
  • 🔒 Security: Alert when a specific person enters a restricted zone
  • ⚽ Sports analytics: Track player positions and movement patterns
🇸🇦 الشرح بالعربي

تتبع الأجسام المتعددة (Multi-Object Tracking) يُضيف البُعد الزمني لاكتشاف الأجسام. بدلًا من تحليل صورة واحدة، يتابع النظام نفس الجسم عبر إطارات الفيديو المتتالية مع الحفاظ على هويته.


المشكلة الأساسية: في الإطار الأول نكتشف شخصًا A وشخصًا B. في الإطار التالي تحركا. كيف نعرف من هو من؟ هذه هي مشكلة "الربط الزمني".


الخوارزميات المستخدمة:

  • مرشح كالمان (Kalman Filter) — يتنبأ بالموقع القادم للجسم بناءً على سرعته واتجاهه الحالي. مثل توقع أين ستهبط الكرة.
  • خوارزمية هانغريان (Hungarian Algorithm) — تحل مشكلة التعيين المثلى: تطابق كل اكتشاف جديد مع أقرب مسار متوقع.
  • Deep SORT — نفس SORT + شبكة عصبية تستخرج "مظهر" الجسم لإعادة التعرف عليه حتى بعد الاختفاء المؤقت.

التطبيقات:

  • 📹 كاميرات المراقبة لعد الأشخاص
  • 🚗 تحليل حركة المرور
  • ⚽ تحليل حركة اللاعبين في كرة القدم

المصطلحات:

  • Object Tracking (تتبع الأجسام) — متابعة نفس الجسم عبر الإطارات
  • Temporal ID Association (الربط الهوياتي الزمني)
  • Kalman Filter (مرشح كالمان) — التنبؤ بالموقع
  • Hungarian Algorithm (خوارزمية هانغريان) — المطابقة المثلى
  • Deep SORT — تتبع بالمظهر البصري العميق
  • Occlusion (الإخفاء) — اختفاء الجسم خلف شيء آخر مؤقتًا
💡 Practical Example — Sports Tracking

During a football match, AI tracking systems:

  1. Detect all 22 players + ball in each frame (object detection)
  2. Kalman Filter predicts where each player will be in the next frame (0.04 seconds later at 25fps)
  3. Hungarian matching assigns each new detection to its corresponding player ID
  4. Deep SORT re-identifies players who go off-screen or get obscured

  3. Layout analysis (zones, columns, lines)

  5. Language model correction (fix "0" vs "O" errors using context)
  6. Output structured text + feed to NLP pipeline

10. Zero-Shot Learning

Detecting Objects the Model Was Never Trained On

🇬🇧 English Explanation
ENGLISH EXPLANATION

Zero-Shot Learning (ZSL) is the ability to recognize or detect objects that the model was never shown during training. This is possible by leveraging semantic relationships and general knowledge.


How does it work?

The Key Insight

Instead of learning "what a zebra looks like" from zebra photos, a ZSL model learns semantic attributes: "a zebra is like a horse with stripes." If it knows what "horse" and "stripes" look like, it can recognize a zebra it's never seen.


Modern ZSL approaches (e.g., CLIP — Contrastive Language-Image Pretraining):

  1. Train on millions of image-text pairs: "a photo of a cat" + cat image
  2. Model learns joint embedding space where similar concepts cluster together
  3. At test time: describe new class in text ("a photo of a pangolin")
  4. Model finds images whose visual features match the text description
  5. Successfully identifies pangolins never seen in training

Why is this important?

  • 🔬 New species or rare medical conditions emerge — can't retrain model every time
  • 🏭 Industrial defects may vary — ZSL detects new defect types
  • 🌍 Scalability: instead of labeling 1000 images per class, describe it in text

11. Feature Extraction

Converting Visual Patterns into Numerical Vectors

🇬🇧 English Explanation
ENGLISH EXPLANATION

Feature Extraction converts an image into a compact numerical vector that captures its essential visual characteristics — like a mathematical "fingerprint" of the image.


How it works with CNNs:

  1. Pass image through a pre-trained CNN (e.g., ResNet-50)
  2. Remove the final classification layer
  3. The second-to-last layer output = the feature vector (e.g., 2048 numbers)
  4. This vector encodes "what the image looks like" in abstract mathematical form

Applications:

🔒 Facial Recognition & Biometric Security

Face feature vectors (~128-512 dimensions) for two faces are compared using cosine similarity or Euclidean distance. If distance < threshold → same person. This is how FaceNet, ArcFace work.

🔍 Reverse Image Search

Google Images: upload a photo → extract its feature vector → search database for nearest-neighbor vectors → return visually similar images.

🛒 Product Recommendation

E-commerce: "shop similar items" — extract feature vector of a dress → find dresses with similar vectors in the product database.

similarity = cos(θ) = (A · B) / (|A| × |B|)    [Cosine Similarity]

Where A and B are feature vectors. Range: -1 (opposite) to 1 (identical). For face verification, typically threshold = 0.6.

🇸🇦 الشرح بالعربي

عند تمرير صورة وجه عبر شبكة CNN مُدرَّبة مسبقًا، نحذف طبقة التصنيف الأخيرة، فيكون الخرج متجه رقمي (مثلًا 512 رقم) يُمثل "شكل الوجه" رياضيًا. لمقارنة وجهين: يُحسب التشابه (cosine similarity) بين المتجهين.

15. OpenCV Code Pipeline — Grayscale Transform

Writing Grayscale Transforms in OpenCV — Standard Pipeline Steps

📋 Original Slide Content

A foundational OpenCV Python script that reads an image, transforms it to grayscale, and displays the output:

  • cv2.imread: Loads the file into memory as a NumPy matrix.
  • cv2.cvtColor: Transforms the BGR array into a single-channel grayscale matrix.
  • cv2.imshow: Opens a native rendering window to display the output.
🇬🇧 English Explanation — Full Code Walkthrough
ENGLISH EXPLANATION

Let's build the complete standard pipeline code with detailed explanations of every function:


import cv2
import numpy as np

# Step 1: Load image from disk into memory
# Returns: NumPy array of shape (height, width, 3) — BGR format
# Note: OpenCV loads as BGR not RGB!
image = cv2.imread('photo.jpg')

# Safety check — file might not exist
if image is None:
    print("Error: Could not load image")
    exit()

# Step 2: Convert BGR to Grayscale
# cv2.COLOR_BGR2GRAY combines 3 channels into 1
# Formula: Gray = 0.114*B + 0.587*G + 0.299*R
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# Step 3: Display results
cv2.imshow('Original (BGR)', image)
cv2.imshow('Grayscale', gray)

# Step 4: Wait for key press, then close all windows
cv2.waitKey(0)  # 0 = wait indefinitely
cv2.destroyAllWindows()

Function-by-Function Explanation:

cv2.imread(filename, flag)

What it does: Reads an image file from disk into RAM as a NumPy ndarray.

Important: OpenCV stores color images as BGR (Blue-Green-Red), NOT RGB! This is a frequent source of bugs when displaying with matplotlib.

Return shape: (height, width, channels) = e.g., (480, 640, 3) for a 640×480 color image

Flags: cv2.IMREAD_COLOR (default), cv2.IMREAD_GRAYSCALE, cv2.IMREAD_UNCHANGED (keep alpha)

cv2.cvtColor(image, code)

What it does: Converts an image between color spaces.

Common codes:

  • cv2.COLOR_BGR2GRAY — to grayscale
  • cv2.COLOR_BGR2RGB — BGR to RGB (for matplotlib)
  • cv2.COLOR_BGR2HSV — to Hue-Saturation-Value
  • cv2.COLOR_GRAY2BGR — grayscale to 3-channel BGR

Grayscale formula: Gray = 0.114×B + 0.587×G + 0.299×R (human perception weights — green channel matters most to human vision)

cv2.imshow(window_name, image)

What it does: Opens a native OS window displaying the image array.

Important: Must be followed by cv2.waitKey() — otherwise the window immediately closes and nothing is visible!

cv2.waitKey(delay_ms)

Waits for a keyboard event for delay_ms milliseconds. 0 = wait forever. Returns ASCII code of pressed key.


Extended Pipeline — Adding More Operations:

import cv2

image = cv2.imread('photo.jpg')
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# Threshold (binarize) the grayscale image
_, binary = cv2.threshold(gray, 128, 255, cv2.THRESH_BINARY)

# Detect edges using Canny algorithm
edges = cv2.Canny(gray, 50, 150)

# Find connected components
num_labels, labels = cv2.connectedComponents(binary)
print(f"Found {num_labels-1} components")

# Save result to disk
cv2.imwrite('output_gray.jpg', gray)
cv2.imwrite('output_edges.jpg', edges)

# Display all results
cv2.imshow('Original', image)
cv2.imshow('Gray', gray)
cv2.imshow('Binary', binary)
cv2.imshow('Edges', edges)
cv2.waitKey(0)
cv2.destroyAllWindows()
