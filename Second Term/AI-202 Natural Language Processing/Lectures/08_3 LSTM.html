1 — What is LSTM?
▼

Normal neural networks process one input and forget everything before. Recurrent Neural Networks (RNNs) tried to fix this by keeping a "memory" from previous steps — but they had trouble remembering things that happened far back in the sequence (this is called the vanishing gradient problem).

LSTM (Long Short-Term Memory) solves this by using a special neuron with an internal memory cell and three "gates" that control what gets stored, what gets forgotten, and what gets output.

Analogy Think of LSTM like a notepad with a selective editor. As you read a book, you can choose which facts to write down, which old facts to erase, and which facts to look at when you need to answer a question. You don't rewrite everything on every page — only what matters.

Key Idea

  • An LSTM neuron has 4 inputs and 1 output
  • It holds a persistent cell state c that can carry information across many time steps
  • Three sigmoid gates control information flow: Input Gate, Forget Gate, Output Gate
Fig 1 — LSTM cell with 4 inputs (z, zi, zf, zo) and 1 output (a)
Summary LSTM is a special RNN unit with a built-in memory cell and three gates. Instead of forgetting everything between time steps, it selectively remembers and forgets — making it powerful for sequences like text, speech, and time series.

الشبكات العصبية العادية بتعالج كل input لوحده وبتنسى كل اللي قبله. الـ RNN حاولت تحل المشكلة دي بإنها تحتفظ بـ"ذاكرة" من الخطوات السابقة — بس كانت بتنسى الأحداث اللي حصلت بعيد في التسلسل (وده اسمه مشكلة الـ vanishing gradient).

الـ LSTM حل المشكلة دي بخلية عصبية خاصة فيها memory cell و3 بوابات (gates) بتتحكم في المعلومات.

تشبيه تخيل الـ LSTM زي دفتر ملاحظات ذكي: وأنت بتقرأ كتاب، بتختار إيه تكتبه، إيه تمسحه، وإيه تبص عليه لما تحتاج تجاوب سؤال. مش بتعيد كتابة كل حاجة في كل صفحة.
  • الـ LSTM عنده 4 inputs وoutput واحد
  • بيحتفظ بـ cell state c بيعدي معلومات عبر الوقت
  • 3 gates بتتحكم في المعلومات: Input Gate، Forget Gate، Output Gate
ملخص الـ LSTM هو وحدة RNN خاصة فيها ذاكرة داخلية و3 بوابات. بدل ما تنسى كل حاجة، بتختار إيه تتذكر وإيه تنسى — وده بيخليها قوية جداً في معالجة النصوص والكلام والسلاسل الزمنية.

2 — The Three Gates
▼

Each gate uses a sigmoid activation function — which outputs a value between 0 and 1. Think of this as a "valve": 0 means fully closed (block everything), 1 means fully open (let everything through).

GateSignalWhat It ControlsEffect
Input Gatef(zi)How much new info enters the cell0 = block input, 1 = accept input
Forget Gatef(zf)How much old memory is kept0 = erase memory, 1 = keep memory
Output Gatef(zo)How much cell state to expose as output0 = silent, 1 = full output

Why Sigmoid?

The sigmoid function maps any value to (0, 1). This "soft" on/off is differentiable — meaning the network can learn the gate weights by backpropagation. A hard 0/1 switch wouldn't allow gradient-based training.

Analogy Think of the three gates as three security guards at a data center.
— The input guard decides whether new data trucks are allowed in.
— The forget guard decides whether old data stored inside stays or gets wiped.
— The output guard decides which data is shared with the outside world.
Fig 2 — Three gates controlling the cell state stream
Summary The three sigmoid gates are the heart of LSTM. They turn information flow on/off smoothly (not hard switches), so the network can learn — via backpropagation — exactly when to remember, forget, and output.

كل gate بيستخدم sigmoid activation function — اللي بتطلع قيمة بين 0 و1. فكر فيها زي "صمام": 0 يعني مقفول تماماً، 1 يعني مفتوح تماماً.

Gateوظيفتهاالتأثير

Forget Gateبتتحكم كام من الذاكرة القديمة يتحفظ0 = امسح، 1 = احتفظ

— حارس الـ Forget: يقرر هل البيانات القديمة تتمسح؟
— حارس الـ Output: يقرر أيه اللي يطلع للعالم برا؟
ملخص الـ3 gates هم قلب الـ LSTM. بيتحكموا في تدفق المعلومات بطريقة سلسة (مش on/off حاد)، عشان الشبكة تقدر تتعلم إمتى تتذكر وإمتى تنسى وإمتى تطلع المعلومة.

3 — The Math Step by Step
▼

There are two key equations inside every LSTM cell. Let's break them down one by one.

Step 1 — Update the Cell State

c' = g(z) · f(zi) + c · f(zf)
  • g(z) — the new candidate value (processed through a tanh-like activation g)
  • f(zi) — input gate: how much of the new value to let in (0–1)
  • c — the previous cell state (old memory)
  • f(zf) — forget gate: how much of the old memory to keep (0–1)
  • The result c' is the new cell state — a blend of new info and old memory

Step 2 — Compute the Output

a = h(c') · f(zo)
  • h(c') — the new cell state passed through activation function h
  • f(zo) — output gate: how much of the cell state to expose as output
  • a — the final output of the LSTM cell at this time step
Concrete Example Suppose f(zi) = 1 (input fully open), f(zf) = 1 (nothing erased), g(z) = 3, and old memory c = 0.
Then: c' = 3 · 1 + 0 · 1 = 3
If f(zo) = 0 (output closed), then a = h(3) · 0 = 0. The value 3 is stored but not shown yet.
Fig 3 — Data flow inside one LSTM cell
Summary Two equations run every time step: one updates the cell state (blending new info with old memory), and one computes the output (filtering the cell state through the output gate). Both are learned end-to-end by gradient descent.

في معادلتين أساسيتين جوه كل LSTM cell. خليني أشرحهم خطوة خطوة.

الخطوة 1 — تحديث الـ Cell State

c' = g(z) · f(zi) + c · f(zf)
  • g(z) — القيمة الجديدة المقترحة (بتعدي على activation function)
  • f(zi) — Input gate: كام من القيمة الجديدة يدخل (من 0 لـ 1)
  • c — الذاكرة القديمة (cell state السابق)
  • f(zf) — Forget gate: كام من الذاكرة القديمة يتحفظ (من 0 لـ 1)
  • النتيجة c' هي الـ cell state الجديد — مزيج من المعلومات الجديدة والقديمة

الخطوة 2 — حساب الـ Output

a = h(c') · f(zo)
  • h(c') — الـ cell state الجديد بعد ما يعدي على دالة تنشيط
  • f(zo) — Output gate: كام منه يطلع كـ output
  • a — الـ output النهائي للـ LSTM cell في هذه اللحظة
مثال عملي لو f(zi)=1 (مفتوح كامل)، f(zf)=1 (مفيش مسح)، g(z)=3، والذاكرة القديمة c=0.
إذن: c' = 3×1 + 0×1 = 3
لو f(zo)=0 (Output مقفول)، إذن a = h(3)×0 = 0. القيمة 3 اتحفظت بس مش اتاخدت بعد.
ملخص في كل خطوة زمنية، معادلتان بيتنفذوا: واحدة بتحدث الـ cell state (بتمزج المعلومات الجديدة مع القديمة)، والتانية بتحسب الـ output (بتفلتر الـ cell state عن طريق Output gate). الاتنين بيتعلموا تلقائياً بالـ gradient descent.

  • When x2 = 1 — add the value in x1 to memory
  • When x2 = -1 — reset (erase) the memory
  • When x3 = 1 — output the current memory value
  • Otherwise — keep memory unchanged, output 0

How LSTM Achieves This

The weights in the LSTM are set so that:

  • x2 = 1 drives the Input Gate open (≈1) — x1's value flows into memory
  • x2 = -1 drives the Forget Gate closed (≈0) — old memory is erased
  • x3 = 1 drives the Output Gate open (≈1) — memory value is shown
  • Large weights (e.g., 100) on x2 push the sigmoid far toward 0 or 1, making gates behave like hard switches

Forget gate signal: 100 × x2 = 100 → sigmoid → ≈ 1 (keep memory)
g(z): passes x1 = 3 through
c' = 3 × 1 + 0 × 1 = 3
Output gate signal: 100 × x3 = 0 → sigmoid → ≈ 0.5... ≈ 0 (closed)
a ≈ 0 — memory stores 3, but nothing is output yet.
Summary This example shows that LSTM can act like a programmable register: a control signal (x2, x3) tells it when to write, erase, and read. The network learns these control weights from data — you don't have to program the gates manually.

5 — Full LSTM Network (Through Time)
▼

In a real LSTM network, you replace every neuron with an LSTM block. Each block receives three things at every time step:

  • x^t — the input at this time step
  • h^(t-1) — the output from the previous time step (hidden state)
  • c^(t-1) — the cell state from the previous time step (long-term memory)

Both c and h flow forward in time like a chain, connecting each step to the next.

Important Note Because each LSTM block has 4 internal weight matrices (for z, zi, zf, zo), replacing neurons with LSTM blocks gives you 4 times more parameters than a regular RNN. This is a trade-off: more expressive but more computationally expensive.

Multiple Layers

In practice, LSTMs are stacked: the output of one layer becomes the input of the next. This is called a deep LSTM or multi-layer LSTM. Libraries like Keras handle this with a single line: model.add(LSTM(units)).

Fig 4 — LSTM unrolled through time. c (cell state) and h (hidden state) pass forward at each step.
Summary At each time step, the LSTM takes the current input plus the previous hidden state (h) and cell state (c), producing a new output and updated states. This chain lets information flow across the full sequence — even long sequences — without vanishing.

في الشبكة الحقيقية، بتستبدل كل neuron بـ LSTM block. كل block بياخد 3 حاجات في كل خطوة زمنية:

  • x^t — الـ input الحالي
  • h^(t-1) — الـ output من الخطوة السابقة (hidden state)
  • c^(t-1) — الـ cell state من الخطوة السابقة (الذاكرة طويلة الأمد)

الـ c والـ h بيتحركوا للأمام في الوقت زي سلسلة، بتربط كل خطوة بالتالية.

ملاحظة مهمة لأن كل LSTM block عنده 4 مصفوفات weights داخلية (لـ z, zi, zf, zo)، استبدال الـ neurons بـ LSTM بيديك 4 أضعاف عدد الـ parameters مقارنة بالـ RNN العادي. ده trade-off: أكتر تعبيراً بس أكتر تكلفة حسابية.

Multiple Layers

عملياً، الـ LSTMs بتتكوم فوق بعض: output الطبقة الأولى بيبقى input الطبقة التانية. ده اسمه deep LSTM. مكتبات زي Keras بتتعامل معاها بسطر واحد: model.add(LSTM(units)).

ملخص في كل خطوة زمنية، الـ LSTM بياخد الـ input الحالي + الـ hidden state + الـ cell state السابقين، وبيطلع output جديد وحالات محدثة. السلسلة دي بتخلي المعلومات تعدي عبر التسلسل كله — حتى لو طويل — من غير ما تختفي.

6 — Why LSTM Solves Gradient Vanishing
▼

In a standard RNN, the hidden state is multiplied by a weight matrix at every step. If that weight is less than 1, repeated multiplication makes it shrink to zero (vanishing gradient). If it's greater than 1, it explodes.

LSTM solves the vanishing gradient because the cell state c is updated by addition, not multiplication:

c' = g(z) · f(zi) + c · f(zf)

As long as the Forget Gate is open (f(zf) ≈ 1), old information is added, not scaled down. The gradient can flow back through time without vanishing.

Limitation LSTM solves gradient vanishing but not gradient exploding. Exploding gradients are handled separately (e.g., by gradient clipping).

GRU — A Simpler Alternative

The Gated Recurrent Unit (GRU), introduced in Cho et al., EMNLP 2014, achieves similar results with only 2 gates instead of 3 — making it faster to train. Keras supports both: LSTM, GRU, SimpleRNN.

ModelGatesParametersStrength
SimpleRNN0FewestFast but forgets
GRU2MediumFast, handles long sequences
LSTM3Most (4×)Powerful, handles very long sequences
Summary LSTM beats standard RNNs because its additive cell state update prevents gradient shrinkage. The forget gate acts like a memory lifeline — keeping important information alive across hundreds of time steps. GRU achieves a good balance with fewer parameters.

في الـ RNN العادي، الـ hidden state بيتضرب في weight matrix في كل خطوة. لو الـ weight أقل من 1، الضرب المتكرر بيخليه يوصل للصفر (vanishing gradient). لو أكبر من 1، بينفجر.

الـ LSTM بيحل المشكلة عشان الـ cell state c بيتحدث بالـ جمع مش الضرب:

c' = g(z) · f(zi) + c · f(zf)

طالما الـ Forget Gate مفتوح (f(zf) ≈ 1)، المعلومات القديمة بتتضاف مش بتتصغر. الـ gradient يقدر يرجع للخلف من غير ما يختفي.

حد للـ LSTM الـ LSTM بيحل الـ gradient vanishing بس مش الـ exploding. الـ exploding بيتعالج بطريقة تانية (زي gradient clipping).

الـ GRU — بديل أبسط
