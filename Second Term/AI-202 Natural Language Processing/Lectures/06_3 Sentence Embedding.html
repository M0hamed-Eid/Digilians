01

Introduction to Sentence Embedding

What it is and why we need it

▼

Sentence Embedding is the collective name for techniques in NLP where entire sentences are converted (mapped) into vectors of real numbers. Think of it as a "fingerprint" of a sentence — a list of numbers that captures what the sentence means.

There are three main approaches:

  • Transformer-based models (BERT / SBERT): Use the hidden layer outputs of a pre-trained transformer to produce a rich vector per sentence. This is the most powerful modern approach.
  • Aggregate word embeddings: Take word vectors (like Word2Vec) and combine them into one sentence vector.
  • CBOW (Continuous Bag-of-Words): Simply compute the average or sum of all word vectors in the sentence. Very fast, but loses word-order information.
Analogy
Just as a GPS coordinate (latitude + longitude) can pinpoint a physical location on Earth, a sentence embedding "coordinates" a sentence inside a high-dimensional meaning-space. Sentences with similar meaning end up with coordinates that are close to each other.

Sentence Embedding هي تقنية في الـ NLP بنحوّل فيها الجمل الكاملة لـ vectors من الأرقام. بدل ما نتعامل مع كلمة كلمة، بنحوّل الجملة كلها لرقم أو مجموعة أرقام تعبّر عن معناها.

في 3 طرق رئيسية:

  • Transformer models زي BERT: بتاخد output من داخل الشبكة العصبية — النتيجة vector غني جداً بالمعنى.
  • تجميع word embeddings: بناخد vectors الكلمات من Word2Vec ونجمعهم في vector واحد للجملة.
  • CBOW: أبسط طريقة — بناخد متوسط أو مجموع vectors كل الكلمات في الجملة.
تشبيه
تخيّل إن كل جملة عندها "إحداثيات جغرافية" في عالم المعنى. الجمل اللي معناها متشابه بتكون إحداثياتها قريبة من بعض. الـ embedding هو اللي بيحدد الإحداثيات دي.
02

Why CBOW Fails — The Word-Order Problem

The fundamental limitation of averaging word vectors

▼

The CBOW approach (averaging word vectors) has a critical flaw: it completely ignores the order of words. Watch what happens:

vec("dog") = (0.2, −0.3, 1.5, ...)
vec("bites") = (0.5, 1.0, −0.4, ...)
vec("man") = (−0.1, 2.3, −1.5, ...)

Sum: vec("dog bites man") = (0.6, 3.0, −0.4, ...)
Avg: vec("dog bites man") = (0.2, 1.0, −0.133, ...)

The problem: since we just add or average the vectors, the result for "dog bites man" is identical to the result for "man bites dog" — they use the same three word vectors!

Critical Problem

"man bites dog" = (same vector as) = "dog bites man" under CBOW. But these sentences have completely opposite meanings! CBOW cannot distinguish them.

Another example: "the quick brown fox jumps over the lazy dog" produces the same CBOW vector as "the lazy fox over the brown dog jumps quick" — completely different meaning, same representation.

This is why we need models that read sentences sequentially and keep track of word order — this is the motivation for RNNs.

الـ CBOW بيجمع أو يعمل متوسط لـ vectors الكلمات — المشكلة إنه بيتجاهل ترتيب الكلمات تماماً.

المشكلة الأساسية

"كلب عض رجل" و"رجل عض كلب" هيطلعوا نفس الـ vector في CBOW — لأن فيهم نفس الكلمات! لكن المعنى مختلف تماماً. الـ CBOW مش قادر يميّز بينهم.

عشان كده محتاجين model يقرأ الجملة كلمة كلمة ويفتكر الترتيب — وده اللي بيعمله الـ RNN.

03

Recurrent Neural Networks (RNN) — The Basics

Sequential processing with memory

▼

What is an RNN?

A Recurrent Neural Network (RNN) is a neural network designed to process sequences of data. Instead of treating each input independently, it processes inputs one-by-one while maintaining a "memory" of what it has seen so far.

Formally: it processes a sequence x(1), x(2), ..., x(t) where t is the time step. The key: the output h(t) at each step depends not just on the current input x(t) but also on the previous hidden state h(t-1).

Analogy — Reading a Book
Imagine reading a mystery novel. When you reach page 50, your understanding depends on everything you've read on pages 1 through 49. An RNN works the same way — each word is processed while carrying forward all previous context.

Applications of RNNs (Sequential tasks)

Task TypeInputOutputExample
Many-to-OneSequence of wordsSingle labelSentiment Analysis ("great movie" → Positive)
One-to-ManySingle imageSequence of wordsImage Captioning
Many-to-ManySentence in EnglishSentence in FrenchMachine Translation
Many-to-Many (same length)Words in a sentenceLabel per wordNamed Entity Recognition (NER)
Things to Memorize
  • RNNs process sequences one step at a time
  • Each step produces a hidden state h(t) that acts as "memory"
  • h(t) depends on both the current input x(t) AND the previous state h(t-1)
  • This is why they're called "recurrent" — the same network cell is reused at every step

إيه هو الـ RNN؟

الشبكة العصبية المتكررة (RNN) هي شبكة عصبية بتعالج البيانات المتسلسلة. فبدل ما تعالج كل input لوحده، بتقرأ الـ input واحدة واحدة وعندها "ذاكرة" بتفتكر اللي حصل قبل كده.

تشبيه
لما بتقرأ رواية وتوصل للصفحة 50، فهمك بيعتمد على كل اللي قرأته قبل كده. الـ RNN بالظبط زي كده — كل كلمة بتتعالج وهي شايلة كل السياق اللي قبلها.

تطبيقات الـ RNN

  • Many-to-One: تحليل المشاعر — جملة كاملة → تصنيف واحد (إيجابي/سلبي)
  • One-to-Many: وصف الصور — صورة واحدة → جملة وصفية
  • Many-to-Many: الترجمة الآلية — جملة إنجليزية → جملة فرنسية
  • Many-to-Many (نفس الطول): NER — كلمة كلمة → تصنيف لكل كلمة
04

How an RNN Actually Works — Step by Step

The unrolling concept explained

▼

Let's trace through how an RNN processes the sentence "What time is it?":

1

Process first word: "What"

Cell A takes x(0) = vec("What") as input, produces hidden state h(0). There's no previous context yet.

2

Process second word: "time"

Cell A now receives BOTH x(1) = vec("time") AND h(0) from the previous step. Output is h(1) which contains context about "What time".

3

This continues word by word...

h(1) and x(2) → h(2), then h(2) and x(3) → h(3), and so on. Each step's hidden state is a summary of everything read so far.

Final

The final hidden state h(t) is the sentence embedding

After the last word, h(t) encodes the meaning of the entire sentence — this becomes the sentence's vector representation.

Key Insight — Why "Recurrent"?
The same neural network cell (A) is applied at every time step. It's "recurrent" because the same weights are reused repeatedly. This makes it memory-efficient — you don't need a new network for each position in the sentence.

خلينا نتتبع إزاي الـ RNN بيعالج جملة "What time is it?":

1

أول كلمة: "What"

الـ cell بياخد vec("What") كـ input ويطلع h(0). لسه مفيش سياق قبله.

2

تاني كلمة: "time"

الـ cell بياخد x(1)=vec("time") وكمان h(0) من الخطوة اللي قبلها. الـ output هو h(1) اللي فيه سياق "What time".

آخر خطوة

الـ hidden state الأخير هو الـ sentence embedding

بعد آخر كلمة، h(t) بيكون فيه معنى الجملة كلها — وده بيبقى الـ vector اللي بيمثل الجملة.

ليه اسمه "Recurrent"؟
لأن نفس الـ cell بيتكرر في كل خطوة — بياخد input الحالية + ذاكرة الخطوة السابقة. الـ weights نفسها بتتستخدم في كل خطوة.

▼

06

Gradients, Vanishing & Exploding

Why training RNNs is hard — and how LSTM helps

▼

What is a Gradient?

A gradient is the derivative of a function with respect to its inputs. Intuitively: "if I change the weights a little bit, by how much does the error change?"

  • Higher gradient = steeper slope = model learns faster
  • Gradient of zero = model stops learning entirely
  • Gradient measures how we should adjust each weight to reduce error

Problem 1: Exploding Gradients

When the gradient values become extremely large, the model assigns massive importance to certain weights, causing chaotic updates. The fix is simple: gradient clipping — cap the gradient value at a threshold so it can't explode.

Problem 2: Vanishing Gradients

When gradients become extremely small (close to zero) during backpropagation through many time steps, the model effectively "forgets" information from early in the sequence. This is the major reason standard RNNs struggle with long sequences.

Analogy — Vanishing Gradient
Imagine trying to whisper a message through 20 people. By the time it reaches the last person, the message is so faint (the gradient is so small) that they can't hear it. The RNN at the end can't learn from mistakes that happened at the beginning of a long sequence.

The solution to vanishing gradients is the LSTM architecture, covered in the next section.

الـ Gradient إيه؟

الـ gradient هو الـ derivative — بيقيس "لو غيّرت الـ weights شوية، الـ error هيتغير قد إيه؟". الـ model بيتعلم لما بيعدّل الـ weights في الاتجاه اللي بيقلل الـ error.

مشكلة 1: Exploding Gradients

لما الـ gradient يبقى كبير جداً — الحل سهل: gradient clipping (قص الـ gradient لو كبر أوي).

مشكلة 2: Vanishing Gradients

ده أخطر — لما الـ gradient يبقى صغير جداً (قريب من صفر)، الـ model بينسى المعلومات اللي في أول الجملة. ده بيأثر كتير لما الجملة تكون طويلة.

تشبيه
تخيل إنك بتمرر رسالة همساً لـ 20 شخص — لحد ما توصل للأخير، تكون بقت خفية جداً ومحدش يقدر يسمعها. الـ RNN في آخر الجملة مش قادر يتعلم من أخطاء حصلت في الأول.

الحل: LSTM اللي هنتعلمه دلوقتي.

LSTM — Long Short-Term Memory

The memory-enhanced RNN that solves vanishing gradients

▼

Long Short-Term Memory (LSTM) is an extension of the standard RNN that adds a cell state (a separate long-term memory channel) and three gates that control what information flows through.

The Three Gates

GateQuestion it answersAction
Input Gate"Should I let new information IN?"Decides which parts of the new input to add to cell state
Forget Gate"Should I FORGET old information?"Decides which parts of the old cell state to erase
Output Gate"What should I OUTPUT right now?"Decides which parts of cell state to expose as the hidden state h(t)
Analogy — LSTM as a Smart Notebook

Imagine the LSTM has a notebook (cell state) and a pen. At each step:

  • Forget gate: "Let me erase things that are no longer relevant" (eraser)
  • Input gate: "Let me write down the new important info" (pen)
  • Output gate: "What part of my notes should I read aloud now?" (mouth)

This way, important information from the beginning of a long sentence (like the subject) can be preserved all the way to the end without the gradient vanishing.

GRU — A Simpler Alternative

The Gated Recurrent Unit (GRU) is a simplified version of LSTM with only two gates (reset gate + update gate). It performs similarly but is computationally cheaper. The diagram in the lecture shows both LSTM and GRU architectures side by side.

Things to Memorize
  • LSTM has 3 gates: Input, Forget, Output
  • LSTM maintains two states: cell state (long-term) + hidden state (short-term)
  • LSTM solves the vanishing gradient problem of standard RNNs
  • GRU is a simplified LSTM with 2 gates
  • LSTMs are the building blocks of the layers in RNN-based sentence encoders

LSTM هو نسخة متطورة من الـ RNN — بتضيف ذاكرة طويلة الأمد (cell state) و3 gates بتتحكم في المعلومات اللي بتدخل وبتخرج وبتتمسح.

الـ 3 Gates

  • Input Gate: "هل أخلّي المعلومة الجديدة دي تدخل؟"
  • Forget Gate: "هل أمسح معلومات قديمة مش محتاجها؟"
  • Output Gate: "إيه اللي هقوله دلوقتي بناءً على الذاكرة؟"
تشبيه
تخيّل إن الـ LSTM عنده دفتر ملاحظات (cell state). في كل خطوة: بيمسح اللي مش مهم (Forget Gate)، بيكتب اللي جديد ومهم (Input Gate)، وبيقرأ جزء من الملاحظات بصوت عالي (Output Gate). كده بيقدر يفتكر معلومات من أول الجملة حتى لو الجملة طويلة.
08

Skip-Thought Vectors

Learning sentence meaning from context sentences

▼

Skip-Thought Vectors are a method for learning sentence embeddings that was directly inspired by Word2Vec's skip-gram model. Just as Word2Vec learns word meanings by predicting surrounding words, Skip-Thought learns sentence meanings by predicting surrounding sentences.

The Architecture

1

Encoder RNN

Takes the current sentence S(i) and encodes it into a fixed-size vector h(i). The encoder is built from an RNN (LSTM or GRU).

2

Previous Decoder RNN

Takes the vector h(i) as input and tries to reconstruct the previous sentence S(i-1).

3

Next Decoder RNN

Takes the same vector h(i) and tries to predict the next sentence S(i+1).

Goal

Training Objective

The model is trained to minimize the reconstruction error of both surrounding sentences. The result: h(i) must capture the full meaning of sentence S(i) since it has to reconstruct both neighbors.

Example — Recipe Sentences

S(i-1): "Fry steak for about 30 seconds on both sides."
S(i): "Set aside for 5 minutes."
S(i+1): "Take puff pastry out of fridge and let reach room temperature."

The encoder must encode S(i) so well that the decoders can reconstruct both neighbors. This forces the vector to capture the cooking context.

Encoder Types

TypeDescriptionVector Size
Uni-skipReads sentence in forward direction only2400
Bi-skipReads both forwards AND backwards, concatenates results2×2400 = 4800
Combined-skipConcatenates uni-skip and bi-skip vectors4800

Training Data

The model was trained on the BookCorpus Dataset: 11,038 books, 74 million sentences, 984 million words, 1.3 million unique words, average 13 words per sentence.

Evaluation

Skip-Thought was evaluated on 8 tasks including:

Semantic Relatedness Paraphrase Detection Image-Sentence Ranking 5 Classification Benchmarks

On the Semantic Relatedness (SICK dataset) task: Pearson correlation of 0.86, which means the model's similarity scores agree strongly with human-assigned similarity scores. The SICK dataset has 4500 training pairs, 500 dev pairs, and 4927 test pairs with scores from 1 (unrelated) to 5 (highly related), averaged across 10 human annotators.

Skip-Thought Vectors طريقة لتعلم الـ sentence embeddings متأثرة بـ Word2Vec. فبدل ما Word2Vec يتعلم معنى الكلمة من الكلمات اللي حواليها، الـ Skip-Thought بيتعلم معنى الجملة من الجمل اللي حواليها.

الفكرة

1

Encoder

بياخد الجملة الحالية S(i) ويحوّلها لـ vector h(i).

2

Previous Decoder

بياخد h(i) ويحاول يتنبأ بالجملة اللي قبلها S(i-1).

3

Next Decoder

بياخد نفس h(i) ويحاول يتنبأ بالجملة اللي بعدها S(i+1).

النتيجة: الـ vector h(i) لازم يكون عنده معنى كامل للجملة عشان يقدر يتنبأ بالجملتين الجانبيتين.

أنواع الـ Encoder

  • Uni-skip: بيقرأ الجملة في اتجاه واحد بس (للأمام)
  • Bi-skip: بيقرأ للأمام وللخلف ويدمجهم — أقوى
  • Combined-skip: بيدمج الاتنين مع بعض

Sent2Vec

Fast, unsupervised sentence embeddings using n-grams

▼

Sent2Vec extends the Word2Vec CBOW training objective to train sentence embeddings instead of word embeddings. It is a simple, fast, unsupervised model.

Key idea: compose sentence embeddings using word vectors + n-gram embeddings. N-grams are groups of consecutive words — bigrams (2-word groups) capture short phrases like "machine learning" or "natural language".

Surprising Finding
For constructing sentence embeddings, the naively averaged word vectors (CBOW style) was shown to actually outperform RNNs and LSTMs on many tasks! This is a well-known surprising result in NLP. It doesn't mean CBOW is always better — but it shows that for certain tasks, simple averaging works surprisingly well.

Code Walkthrough

Python — Sent2Vec Usage
from sent2vec.vectorizer import Vectorizer
from scipy import spatial

# Define sentences to embed
sentences = [
    "This is an awesome book to learn NLP.",
    "Sent2Vec is an amazing NLP model.",
    "We can interchangeably use embedding, encoding, or vectorizing.",
]

# Create vectorizer and run it
vectorizer = Vectorizer()
vectorizer.run(sentences)
vectors = vectorizer.vectors

# Each vector has 768 dimensions
print(len(vectors[0]))  # → 768

# Compute cosine DISTANCE between sentence 0 and 1
dist_1 = spatial.distance.cosine(vectors[0], vectors[1])
# dist_1 = 0.0509  → very SIMILAR (small cosine distance)

dist_2 = spatial.distance.cosine(vectors[0], vectors[2])
# dist_2 = 0.1921  → less similar (larger cosine distance)
Important Note — Cosine Distance vs Cosine Similarity

Here we use spatial.distance.cosine which returns the cosine distance (1 - cosine similarity). Lower distance = more similar. Sentence 0 and 1 both talk about NLP books/models, so their distance is small (0.05). Sentence 2 is about a broader topic, so its distance is larger (0.19).

Sent2Vec بيمدّد فكرة الـ Word2Vec CBOW عشان يتعلم embeddings للجمل بدل الكلمات. هو model بسيط وسريع وغير supervised.

الفكرة: بيدمج word vectors + n-gram embeddings (مجموعات من كلمتين أو أكتر متجاورة).

نتيجة مفاجئة
متوسط الـ word vectors (CBOW) ثبت إنه بيتفوق على الـ RNN و LSTM في بعض المهام! ده مش معناه إن CBOW دايماً أفضل — لكنه بيوضح إن بعض الأحيان البساطة بتشتغل زي الجِدّة.

Short Answer Grading (SAG)

Using sentence embeddings to automatically grade student answers

▼

Short Answer Grading (SAG), also called Automatic Answer Grading (AAG), is a system that automatically assigns a grade to a student's answer by comparing it with one or more model (correct) answers using text similarity.

Why Automatic Scoring?

Reduces grading time Consistent scoring Handles varied responses Provides instant feedback

Easy for: Multiple Choice, True/False, Fill-in-the-blank. Hard for: Free-text answers — because students can express the same correct concept in many different ways.

Real Example (from the lecture)

Example — Grading "Define Plankton?"

Question: "عرف الهائمات؟" (Define Plankton?)

Model Answer: "Small sized plant or animal organisms that are carried by waves without resistance due to their small bodies."

Student 1: "Tiny microscopic plant or animal organisms that live in surface water of seas that are carried by waves without resistance." → Grade: 5/5 (predicted: 4/5)

Student 2: "Organisms that spread in the surface layer of seas and are carried by waves without resistance." → Grade: 3/5 (predicted: 3/5)

The SAG Pipeline

1

Embed both texts

Convert the student's answer AND the model answer into sentence embedding vectors.

2

Compute similarity

Calculate a similarity score between the two vectors (e.g., cosine similarity).

3

Normalize and scale

Normalize the similarity value and scale it to the grading range (e.g., 0–5).

4

Feed into classifier

Use the similarity value(s) as features into an ML/DL model that predicts the final grade.

Challenges

  • Lack of annotated datasets: Hard to find labeled data with human-graded answers.
  • Multiple valid similarity levels: "slightly correct", "partially correct", "fully correct" — need fine-grained measurement.
  • Evaluation biases: Different human graders may score the same answer differently.
  • Difficulty forming feedback: Not enough to give a grade — systems should also explain WHY.

Evaluation Metrics for SAG

Quadratic Weighted Kappa (QWK) Mean Absolute Error (MAE) Pearson Correlation Coefficient

Short Answer Grading (SAG) نظام بيديّ الطالب درجة على إجابته تلقائياً — بالمقارنة مع الإجابة النموذجية باستخدام text similarity.

الإجابات القصيرة بتبقى صعبة لأن كل طالب ممكن يعبّر عن نفس المعنى بطريقة مختلفة — ومحتاج الـ model يفهم المعنى مش يطابق الكلمات.

الخطوات

1

Embed النصين

بنحوّل إجابة الطالب + الإجابة النموذجية لـ sentence vectors.

2

بنحسب التشابه

Cosine Similarity بين الـ vectors الاتنين.

3

Normalize وScale

بنحوّل قيمة التشابه لدرجة في النطاق المطلوب (0–5 مثلاً).

Types of Text Similarity

String-based vs Semantic-based approaches

▼

When measuring how similar two texts are, there are two fundamentally different approaches:

CategorySubcategoryHow it worksExample
String-Based
(surface level)		 Character-Based Compare texts character by character (edit distance, Levenshtein) "cat" vs "bat" → 1 edit apart
Term-Based Compare overlapping words/terms (TF-IDF, Jaccard) Count shared words between two texts
Semantic-Based
(meaning level)		 Corpus-Based Use a large text corpus to learn word/sentence similarity (LSA, Word2Vec) "car" and "automobile" have high similarity
Knowledge-Based Use an ontology or knowledge graph (WordNet) Words in the same category = similar
Embedding-Based Use sentence/word embedding vectors and cosine similarity BERT embeddings, Skip-Thought, Sent2Vec
For NLP Applications Today

Embedding-based similarity (under Semantic-Based) is the dominant modern approach. It captures nuanced meaning that string-based methods completely miss. "A dog attacked a man" and "A man was bitten by a canine" are very similar semantically but have almost no word overlap.

في طريقتين أساسيتين لقياس التشابه بين نصين:

  • String-Based (مبني على الحروف والكلمات):
    • Character-Based: بيقارن حرف حرف (مثل: Levenshtein distance)
    • Term-Based: بيعد الكلمات المشتركة (مثل: Jaccard, TF-IDF)
  • Semantic-Based (مبني على المعنى):
    • Corpus-Based: بيتعلم التشابه من corpus كبير (Word2Vec, LSA)
    • Knowledge-Based: بيستخدم قاموس معرفي زي WordNet
    • Embedding-Based: بيستخدم vectors وCosine Similarity — ده الأقوى حالياً

Automated Essay Scoring (AES)

From essay text to a quality score

▼

Automated Essay Scoring (AES) is a computer-based system that automatically grades an essay by analyzing various features. It is a form of NLP applied to educational assessment.

Unlike SAG (which compares with a model answer), AES typically has no model answer to compare against — it evaluates the essay on its own merit.

Types of Features Extracted

Feature TypeExamples
Statistical Essay length, number of sentences, sentence length, word length, N-grams, spelling error count
Style-Based Word choice, sentence structure/syntax, punctuation, conjunctions, Part-of-Speech (POS) counts (nouns, verbs, adjectives, adverbs)
Content-Based Cohesion, coherence, relevance of information, semantic similarity, domain knowledge coverage

AES Techniques

ML Regression Models ML Classification Models Ontology-Based Models Deep Learning / Neural Networks

AES Challenges

  • No model answer: Unlike SAG, there's nothing to compare against — the model must judge quality holistically.
  • Lack of annotated datasets: Hard to get large amounts of human-graded essays.
  • Evaluation biases: Even human graders disagree on essay scores.
  • Plagiarism: Students might copy text that "looks good" to the model but isn't original work.

Evaluation Metrics

Same as SAG: Quadratic Weighted Kappa, Mean Absolute Error, Pearson Correlation Coefficient.

Automated Essay Scoring (AES) نظام بيقيّم المقالات تلقائياً عن طريق استخراج features متعددة من النص.

الفرق عن SAG: هنا مفيش إجابة نموذجية نقارن بيها — الـ model لازم يحكم على جودة المقالة لوحده.

أنواع الـ Features

  • Statistical: طول المقالة، عدد الجمل، عدد الكلمات، أخطاء الإملاء
  • Style-Based: اختيار الكلمات، بنية الجمل، علامات الترقيم، أجزاء الكلام (أسماء، أفعال، صفات)
  • Content-Based: التماسك، الاتساق، الصلة بالموضوع، semantic similarity

Question Answering (QA) Systems

The three-module pipeline for automatic QA

▼

A Question Answering (QA) system takes a natural language question and automatically finds or generates an answer from a knowledge source. Think Google, Siri, Alexa — all are QA systems.

Three-Module Architecture

1

Module 1 — Question Analysis

The incoming question goes through: Preprocessing → Syntactic & Semantic Analysis → Question Classification (What type of answer is expected? A person? A place? A date?) → Answer Type Recognition → Focus & Intent Recognition (What exactly is the user asking for?)

2

Module 2 — Passage Retrieval

From a large Document Corpus + Knowledge Base → Indexing → Candidate Document Retrieval → Candidate Passage Extraction → Candidate Passage Ranking. The goal: find the paragraphs most likely to contain the answer.

3

Module 3 — Answer Extraction

From the retrieved passages: Candidate Answers Extraction → Candidate Answers Ranking → Answer Generation → Answer Validation. The final output is the best answer.

How Sentence Embedding Helps Here

Sentence embeddings power the Passage Retrieval step — by embedding both the question and candidate passages, the system can rank passages by semantic similarity (not just keyword matching). This is the foundation of modern retrieval-augmented generation (RAG) systems used in AI today.

Question Answering (QA) نظام بياخد سؤال طبيعي ويرد عليه تلقائياً من مصدر معرفة. زي Google أو Siri.

المكونات الـ 3

1

تحليل السؤال (Question Analysis)

Preprocessing → تحليل نحوي ودلالي → تصنيف السؤال (هل الإجابة شخص؟ مكان؟ تاريخ؟) → التعرف على نوع الإجابة وهدف السؤال

2

استرجاع الفقرات (Passage Retrieval)

من Corpus الوثائق → Indexing → استرجاع الوثائق المرشحة → استخراج الفقرات → ترتيبها حسب الصلة

3

استخراج الإجابة (Answer Extraction)

استخراج إجابات مرشحة → ترتيبها → توليد الإجابة → التحقق منها

دور الـ Sentence Embedding
الـ sentence embeddings بتساعد في الـ Passage Retrieval — بنحوّل السؤال والفقرات لـ vectors ونرتبهم حسب الـ cosine similarity. ده أساس أنظمة الـ RAG الحديثة.

Interview & HR Questions

Technical + behavioral questions to prepare

▼

Technical Interview Questions

What is sentence embedding and how does it differ from word embedding? ▼

Word embeddings (like Word2Vec) produce one vector per word. Sentence embeddings produce one vector for an entire sentence, capturing not just individual word meanings but their combination and order. Methods range from naive CBOW averaging (sum/avg of word vectors) to sophisticated approaches like Skip-Thought, Sent2Vec, and BERT-based sentence encoders (SBERT).

Why does CBOW fail for sentence representation? ▼

CBOW ignores word order. "Dog bites man" and "Man bites dog" produce identical CBOW vectors since they contain the same words. These sentences have opposite meanings, so any system relying on CBOW would treat them as equivalent. CBOW also loses contextual relationships between words in a sentence.

Explain the vanishing gradient problem in RNNs and how LSTM solves it. ▼

During backpropagation through time (BPTT), gradients are multiplied at each time step. If these values are less than 1, repeated multiplication causes them to shrink exponentially — effectively reaching zero for steps far back in the sequence. The network can no longer learn from early inputs. LSTM solves this by adding a cell state (a direct "highway" for gradient flow) and a forget gate that can learn to preserve gradients unchanged, allowing gradients to flow unchanged across many time steps.

What is the training objective of Skip-Thought Vectors? ▼

Skip-Thought uses an encoder-decoder architecture. The encoder converts a sentence S(i) into a fixed vector h(i). Two decoders then attempt to reconstruct the previous sentence S(i-1) and the next sentence S(i+1) from h(i). The model is trained to minimize reconstruction error. This forces h(i) to capture the full semantic content of the sentence, since it must encode enough information to reconstruct both surrounding sentences.

How does Short Answer Grading work as an NLP problem? ▼

SAG is fundamentally a text similarity problem. Both the student's answer and the model answer are converted to sentence embeddings. A similarity score (e.g., cosine similarity) is computed between the vectors. This similarity value is then normalized/scaled to a grading range and optionally fed into an ML classifier to predict the final grade. The key insight: we want semantic similarity, not just word overlap — "automobile" and "car" should match even though they're different words.

What's the difference between String-Based and Semantic-Based text similarity? ▼

String-based similarity compares texts at the surface level — counting character edits (Levenshtein) or overlapping words (Jaccard, TF-IDF). It requires texts to share actual characters/words to be considered similar. Semantic-based similarity compares meaning — two sentences with no words in common can still score high similarity if their embeddings point in the same direction in vector space. "The child is running" and "The kid is sprinting" might have zero word overlap but very high semantic similarity.

What is an n-gram and how does Sent2Vec use it? ▼

An n-gram is a contiguous sequence of n words. Unigrams are individual words; bigrams are pairs of consecutive words (e.g., "machine learning", "natural language"); trigrams are triples. Sent2Vec composes sentence embeddings from both unigram word vectors AND n-gram embeddings. Including bigrams lets the model capture short phrases as units, giving better representations than word-only approaches.

What are the three modules of a QA system? ▼

1. Question Analysis: Preprocesses the question, performs syntactic/semantic analysis, classifies the question type, and determines what kind of answer is expected (person, place, date, etc.). 2. Passage Retrieval: Searches a document corpus, retrieves candidate documents, extracts relevant passages, and ranks them. 3. Answer Extraction: From ranked passages, extracts candidate answers, ranks them, generates the final answer text, and validates it.

Behavioral / HR Questions

How would you explain sentence embeddings to a non-technical stakeholder? ▼

I'd say: "Imagine every sentence gets a GPS coordinate — a set of numbers that pinpoints its meaning in space. Sentences that mean similar things get similar coordinates. Once sentences are turned into these coordinates, a computer can mathematically compare them, even if they use completely different words. This is what allows our system to understand that a student who wrote 'tiny aquatic microorganisms carried by currents' understood the same concept as the model answer about plankton."

Describe a real-world application where sentence embeddings provide clear business value. ▼

Customer support automation: Rather than keyword matching, a company can embed both customer messages and their resolved support ticket database. New messages are embedded and matched to the most semantically similar past ticket, surfacing the correct resolution instantly. This reduces ticket handling time and improves consistency. Sentence embeddings enable true semantic search — "my app keeps crashing" matches "application instability" even without shared words.

Quick Summary
  • Sentence embedding = converting a full sentence to a vector of numbers that captures its meaning
  • CBOW (sum/avg word vectors) ignores word order — "dog bites man" == "man bites dog"
  • RNN processes sequences step-by-step, maintains a hidden state (memory)
  • LSTM solves vanishing gradients with 3 gates: Input, Forget, Output + a cell state
  • Skip-Thought learns sentence meaning by predicting surrounding sentences (encoder-decoder)
  • Sent2Vec extends CBOW to sentence level using word + n-gram vectors
  • SAG = text similarity between student answer and model answer → grade
  • Text similarity: String-Based (surface) vs Semantic-Based (meaning/embeddings)
  • AES grades essays using Statistical, Style-Based, and Content-Based features
  • QA systems: Question Analysis → Passage Retrieval → Answer Extraction
