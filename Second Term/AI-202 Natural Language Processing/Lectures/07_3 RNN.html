Why do we need RNNs? — The memory problem ▾

A regular feedforward neural network processes each input in isolation — it has no memory of previous inputs. That works for classifying a single image, but it fails for language, where word order and context determine meaning.

▶ Motivating Example — Slot Filling

Given the sentence "I would like to arrive Taipei on November 2nd", a ticket-booking system must tag each word with its role:

arrive → other  |  Taipei → destination  |  November 2nd → time

But consider: "I would like to leave Taipei on November 2nd"

Taipei → place of departure

The word "Taipei" is identical in both sentences. A feedforward net gives the same output for the same input — it cannot distinguish the two cases without remembering the preceding verb.

This shows that the network needs memory: a way to carry context from earlier words into the processing of the current word.

💡 Analogy

Imagine reading a novel one word at a time, but forgetting every word the instant you move to the next. You couldn't tell who "he" refers to, or whether "bank" means a riverbank or a financial institution. That is exactly the limitation of a feedforward network on text.

✦ Summary

Feedforward networks process each input independently — no memory of past inputs. Language tasks require context. RNNs solve this by maintaining a hidden state that carries information across time steps.

الشبكة العصبية العادية (feedforward network) بتشوف كل input لوحده — مفيش ذاكرة لأي حاجة اتقالت قبل كده. ده بيكون مشكلة في اللغة، لأن ترتيب الكلام والسياق بيفرقوا جداً في تحديد المعنى.

▶ مثال أساسي — Slot Filling

في جملة "I would like to arrive Taipei on November 2nd"، النظام لازم يحدد دور كل كلمة:

Taipei ← وجهة السفر (destination)

لكن في جملة "I would like to leave Taipei on November 2nd":

Taipei ← مكان المغادرة

كلمة "Taipei" واحدة في الجملتين. الشبكة العادية بتديها نفس الناتج لأنها مش عارفة الفعل اللي قبلها — محتاج ذاكرة!

💡 تشبيه

تخيل إنك بتقرأ رواية كلمة كلمة، وبتنسى كل كلمة فور ما بتقرأ التالية. مش هتعرف "هو" بيشير لمين، ولا "بنك" يعني مصرف ولا ضفة نهر. ده بالظبط قصور الـ feedforward network في فهم النصوص.

✦ الفكرة

الشبكات العادية بتعالج كل input بشكل مستقل — بدون ذاكرة. مهام اللغة تحتاج سياق. الـ RNN بيحل ده بـ hidden state بينقل المعلومات من خطوة لخطوة.

Representing words as vectors — 1-of-N encoding ▾

Neural networks operate on numbers, not words. Every word must be converted into a vector before it can be processed. The simplest technique is 1-of-N encoding (also called one-hot encoding).

Each word in the vocabulary occupies one position in the vector. That word's vector is all zeros except for a 1 at its own position. The vector length equals the vocabulary size.

▶ Example

Vocabulary = {apple, bag, cat, dog, elephant}

apple = [1, 0, 0, 0, 0]

cat = [0, 0, 1, 0, 0]

elephant = [0, 0, 0, 0, 1]

What about words not in the vocabulary (like "Gandalf" or "Sauron")? A simple fix is to add an "other" dimension — any unknown word maps to that single slot.

Property1-of-N encodingWord embeddings (modern)
Vector sizeVocabulary size (often 50,000+)Fixed small size (e.g. 300)
Captures similarity?No — every word is equally distantYes — similar words are nearby
Handles unknowns?Via "other" dimensionVia subword tokenization
ComplexityVery simpleRequires pretraining
✦ Summary

1-of-N encoding is a simple starting point: one vector position per word, all zeros except a single 1. It doesn't capture word meaning or similarity, and vectors can be very large. Modern systems use dense word embeddings instead, but 1-of-N builds the intuition.

الشبكات العصبية بتشتغل بأرقام مش كلام. كل كلمة لازم تتحول لـ vector (قائمة من الأرقام) قبل ما تعالجها الشبكة. أبسط طريقة هي 1-of-N encoding أو اللي بتُعرف بـ one-hot encoding.

كل كلمة في القاموس بياخد مكان واحد في الـ vector. الـ vector كله أصفار ماعدا 1 في مكان الكلمة دي بالذات. طول الـ vector = حجم القاموس.

▶ مثال

القاموس = {apple, bag, cat, dog, elephant}

apple = [1, 0, 0, 0, 0]

cat = [0, 0, 1, 0, 0]

elephant = [0, 0, 0, 0, 1]

لو الكلمة مش موجودة في القاموس؟ بنضيف خانة "other" — أي كلمة غريبة بتروح فيها.

العيب الأكبر: الـ vectors كبيرة جداً وفارغة، ومش بتعبر عن معنى الكلمات أو التشابه بينها. الأنظمة الحديثة بتستخدم word embeddings — vectors صغيرة ومكثفة بتحتوي على المعنى الفعلي للكلمة.

✦ الفكرة

1-of-N encoding بيحول الكلمة لـ vector كله أصفار ما عدا 1 واحد. بسيط لكن ما بيعبرش عن معنى الكلمات. حجم الـ vector = حجم القاموس. الأنظمة الحديثة بتستخدم word embeddings بدلاً منه.

How the RNN works — hidden state and memory ▾

An RNN processes a sequence one step at a time. At each step t it takes two inputs: the current word vector x(t), and the hidden state a(t-1) from the previous step. It computes a new hidden state, produces an output, and stores the hidden state as memory for the next step.

Crucially, the same weight matrices are reused at every time step — the RNN is not a different network for each word, but one network run repeatedly with evolving memory.

// At each time step t: a(t) = f( W_i · x(t) + W_h · a(t-1) ) // new hidden state y(t) = g( W_o · a(t) ) // output // W_i, W_h, W_o — learned weight matrices (shared across all t) // a(0) — initialised to zero
💡 Analogy

Think of a person filling out a form while reading a document sentence by sentence. After each sentence they update a sticky note (the hidden state) with key facts seen so far. When the next sentence arrives, they read it together with the sticky note. The same brain processes each sentence, but the sticky note carries context forward.

Because the same network is reused, the sequence order matters: swapping "arrive Taipei" to "leave Taipei" changes the hidden state when "Taipei" is processed, so the output for "Taipei" is different — exactly what we want.

✦ Summary

At each step the RNN combines the current input with the previous hidden state to produce a new hidden state and an output. The hidden state acts as memory, passing context through the entire sequence. The same weights are shared at every step.

الـ RNN بيشتغل على السيكوانس خطوة خطوة. في كل خطوة t بياخد: الـ input الحالي x(t)، وhidden state a(t-1) من الخطوة اللي قبلها. بيحسب hidden state جديد، وبيطلع ناتج، وبيحفظ الـ hidden state كذاكرة للخطوة الجاية.

الفكرة الأساسية: نفس الـ weights بتتكرر في كل خطوة — مش شبكة مختلفة لكل كلمة، لكن نفس الشبكة بتتشغل مرات كتير مع ذاكرة بتتطور.

// في كل خطوة زمنية t: a(t) = f( W_i · x(t) + W_h · a(t-1) ) // hidden state جديد y(t) = g( W_o · a(t) ) // الناتج
💡 تشبيه

تخيل شخص بيملا استمارة وهو بيقرأ وثيقة جملة جملة. بعد كل جملة بيكتب ملاحظات على ورقة صغيرة (الـ hidden state). لما بييجي للجملة الجاية بيقرأ الجملة الجديدة + ملاحظاته مع بعض. نفس العقل بيشتغل في كل مرة، بس الورقة بتنقل السياق للأمام.

✦ الفكرة

في كل خطوة الـ RNN بيجمع الـ input الحالي مع الـ hidden state السابق عشان ينتج hidden state جديد وناتج. الـ hidden state هو "الذاكرة" اللي بتنقل السياق عبر كل السيكوانس. نفس الـ weights بتتشارك في كل خطوة.

RNN variants — Elman, Jordan, Bidirectional, Deep ▾

Several RNN architectures differ in what they store as memory and how they read the sequence:

ArchitectureWhat goes into memory?Key characteristic
Elman Network Hidden layer activations a(t) The standard RNN. Memory = internal representation.
Jordan Network Previous output y(t) Memory = what the model predicted last time. Useful when the output itself is informative context.
Bidirectional RNN Hidden states from both directions Runs two RNNs simultaneously: one left→right, one right→left. Each position sees the whole sequence.
Deep RNN Multiple stacked layers Several RNN layers stacked vertically, each layer processing the hidden states of the layer below.
▶ Why bidirectional matters

"The animal didn't cross the street because it was too tired."

What does "it" refer to — the animal or the street? You need to read the rest of the sentence to know. A unidirectional RNN has already moved past "it" when it encounters "tired"; a bidirectional RNN's reverse pass has that information available when processing "it".

✦ Summary

Elman stores hidden activations; Jordan stores outputs. Both are unidirectional. Bidirectional RNNs read the sequence in both directions, giving every token a view of the whole context. Deep RNNs stack multiple layers for richer representations.

في أشكال مختلفة للـ RNN بتختلف في إيه اللي بيتحفظ كذاكرة وازاي بيقرأ السيكوانس:

المعمارإيه اللي بيتحفظ؟الخاصية الأساسية
Elman Network Hidden layer activations a(t) الـ RNN الأساسي. الذاكرة = التمثيل الداخلي.
Jordan Network الناتج السابق y(t) الذاكرة = اللي الموديل توقعه المرة اللي فاتت.
Bidirectional RNN Hidden states من الاتجاهين بيشغل RNNين: واحد من اليسار لليمين، وواحد من اليمين لليسار. كل موضع بيشوف الجملة كلها.
Deep RNN طبقات متعددة فوق بعض طبقات RNN متراصة، كل طبقة بتعالج hidden states الطبقة تحتها.
▶ ليه Bidirectional مهم

جملة: "The animal didn't cross the street because it was too tired."

كلمة "it" بترجع لإيه — الحيوان ولا الشارع؟ محتاج تقرأ باقي الجملة عشان تعرف. الـ unidirectional RNN عدى على "it" قبل ما يوصل لـ "tired"؛ الـ bidirectional RNN عنده المعلومة دي لما بيعالج "it".

✦ الفكرة

Elman بيحفظ hidden activations؛ Jordan بيحفظ outputs. الاتنين unidirectional. Bidirectional بيقرأ السيكوانس في الاتجاهين، فكل token عنده سياق كامل. Deep RNNs بتكوّم طبقات لتمثيلات أغنى.

Training RNNs — BPTT and gradient problems ▾

RNNs are trained using Backpropagation Through Time (BPTT). The idea: unroll the RNN across all time steps to form a very deep feedforward network, then apply standard backpropagation. The weight update rule is:

w ← w − η · ∂L/∂w

where η is the learning rate and L is the total loss summed over all time steps.

⚠ The gradient problem

Because the weight matrix W_h is multiplied at every step, gradients propagating backwards can either shrink exponentially to zero (vanishing gradient) or grow exponentially (exploding gradient).

From the lecture's toy example: with w multiplied 999 times…

w = 1.00 → y¹⁰⁰⁰ = 1 (stable)
w = 1.01 → y¹⁰⁰⁰ ≈ 20,000 (exploding)
w = 0.99 → y¹⁰⁰⁰ ≈ 0 (vanishing)

A tiny change in w causes a massive or negligible change in output — making the gradient either huge or essentially zero.

In practice the error surface is very rough: mostly flat (vanishing), but with sudden steep cliffs (exploding). This is visible in the lecture's training curves, where loss sometimes spikes violently.

ProblemSymptomCommon fix
Vanishing gradient Network cannot learn long-range dependencies; early layers receive near-zero gradients Use LSTM or GRU architectures
Exploding gradient Loss spikes wildly; NaN values; instability Gradient clipping: cap gradient norm at a threshold before the update

The deeper architectural fix is to use LSTM (Long Short-Term Memory) or GRU (Gated Recurrent Unit). These use gating mechanisms to explicitly control what information to store, update, or forget — largely solving the vanishing gradient problem.

✦ Summary

BPTT unrolls the RNN through time and applies backpropagation. The main challenge is vanishing/exploding gradients due to repeated multiplication of W_h. Gradient clipping addresses explosions; LSTM and GRU architectures address vanishing gradients.

الـ RNNs بتتدرب باستخدام Backpropagation Through Time (BPTT). الفكرة: بنفرد الـ RNN عبر كل الخطوات الزمنية عشان يبقى شبه شبكة عميقة جداً، وبعدين نطبق الـ backpropagation العادي. قاعدة تحديث الـ weights:

w ← w − η · ∂L/∂w
⚠ مشكلة الـ Gradients

لأن الـ weight matrix W_h بتتضرب في كل خطوة، الـ gradients اللي بترجع للخلف ممكن إما تـتتلاشى لقريبة من الصفر (vanishing gradient) أو تـتكبر بشكل هائل (exploding gradient).

من المثال في الشرائح: مع ضرب w ألف مرة…

w = 1.00 → y^1000 = 1 (مستقر)
w = 1.01 → y^1000 ≈ 20,000 (exploding)
w = 0.99 → y^1000 ≈ 0 (vanishing)

تغيير بسيط جداً في w بيعمل فرق ضخم أو معندهوش تأثير خالص — ده بيخلي الـ gradient إما ضخم أو صفر تقريباً.

المشكلةالأعراضالحل الشائع
Vanishing gradient الشبكة مش عارفة تتعلم الروابط البعيدة LSTM أو GRU
Exploding gradient الـ loss بيقفز فجأة — تدريب غير مستقر Gradient clipping

الحل الأعمق هو استخدام LSTM أو GRU. بيستخدموا gating mechanisms عشان يتحكموا صراحة في إيه اللي يتحفظ وإيه اللي يُنسى — ده بيحل مشكلة الـ vanishing gradient بشكل كبير.

✦ الفكرة

BPTT بيفرد الـ RNN عبر الزمن ويطبق backpropagation. التحدي الأساسي هو الـ vanishing/exploding gradients من الضرب المتكرر لـ W_h. Gradient clipping بيعالج الـ exploding؛ LSTM وGRU بيعالجوا الـ vanishing.
